34	### AD-05: Seeds from SeedSequence, disjoint held-out ranges, one process per run
35	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** system
36	- **Context:** WORLD-01, WORLD-02, TRAIN-02 and REPLAY-02 need exact repeats; TRAIN-04 and EVAL-03 need seeds never used in training; TRAIN-05 and QR-02 need runs in parallel, one per core.
37	- **Decision:** A run seed spawns the learner's, exploration and episode-seed generators through `np.random.SeedSequence`. An episode seed spawns the world's and the policies' generators inside `core.play_episode`. Training draws episode seeds from [0, 10⁶); evaluation seeds are the fixed `core.EVAL_SEEDS` and `core.FINAL_SEEDS` ranges (see Data). `train.run_batch` runs each config in its own `spawn` process with `torch.set_num_threads(1)` and `torch.use_deterministic_algorithms(True)`.
38	- **Alternatives:** Global `np.random.seed`/`torch.manual_seed`: order-dependent, breaks once evaluation interleaves with training. Threads: the GIL serialises the Python world loop.
39	- **Consequences:** Identical runs are promised on the same machine only (TRAIN-02). In-training evaluation never touches the training generators, so turning evaluation off for a test leaves training identical.

42	### AD-06: Run folders of JSON, JSON Lines and torch checkpoints
43	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** system
44	- **Context:** LOG-01 and LOG-02 need a record and per-episode logs. LOG-06 needs them readable while the run writes, at most one evaluation point behind. A stopped run keeps its checkpoints and is marked incomplete. A run name that already exists is refused (TRAIN edge cases). REPLAY edge cases need a checkpoint to carry its world spec.
45	- **Decision:** One folder per run (see Data). Logs are append-only JSON Lines, flushed at every evaluation point; `run.json` is rewritten atomically (write, then rename) on each status change. A checkpoint is a `torch.save` dict of spec, method configs and state dicts, loaded with `weights_only=True`.
46	- **Alternatives:** Parquet: fast to read but not appendable while a run is live. SQLite: one file for everything, but concurrent writers from parallel runs need care and the files are no longer readable by eye.
47	- **Consequences:** Charts and evaluation read whole JSONL files; at ~10⁴ episodes per run that is instant. A crashed process leaves `run.json` at `running`; `runlog` reports any `running` run with no live process as incomplete.

def train_loop(
    world: World, learners: Mapping[str, Learner], config: RunConfig, root: Path
) -> RunRecord:
    """Exactly `budget` world steps, written through `runlog.RunWriter`, with checkpoints at
    every 10% and evaluations on `EVAL_SEEDS` at every 5%."""
    writer = RunWriter(root, config, world.spec)
    eval_world = copy.deepcopy(world)  # evaluation never disturbs the training episode
    explore, episode_seeds = _generators(config.seed)
    marks = _marks(config.budget)
    _mark(writer, eval_world, learners, 0, marks.get(0, []))
    obs, length = world.reset(_draw_seed(episode_seeds)).obs, 0
    for step in range(1, config.budget + 1):

            last, length = world.reset(_draw_seed(episode_seeds)), 0

        _mark(writer, eval_world, learners, step, marks.get(step, []))

def _generators(seed: int) -> tuple[np.random.Generator, np.random.Generator]:
    """The exploration and episode-seed generators: children 1 and 2 of the run seed's
    `SeedSequence`; child 0 seeds the learners (AD-05)."""
    children = np.random.SeedSequence(seed).spawn(3)
    return np.random.default_rng(children[1]), np.random.default_rng(children[2])


def _draw_seed(rng: np.random.Generator) -> int:
    return int(rng.integers(0, TRAIN_SEEDS))


def _marks(budget: int) -> dict[int, list[int]]:
    """The step of each evaluation percentage, 0, 5, … 100, rounded down."""
    marks: dict[int, list[int]] = {}
    for pct in range(0, 101, EVAL_EVERY):
        marks.setdefault(budget * pct // 100, []).append(pct)
    return marks


def _train_step(world: World, learners: Mapping[str, Learner], obs: Array, rng: np.random.Generator) -> Step:
    """Every team acts on its rows of `obs`, the world steps once, every team observes."""
    teams = world.spec.teams
    acts = {team.name: learners[team.name].act(obs[list(team.agents)], rng) for team in teams}
    rows = {i: a for team in teams for i, a in zip(team.agents, acts[team.name], strict=True)}
    nxt = world.step(np.stack([rows[i] for i in range(len(world.spec.agents))]))
    for team in teams:
        agents = list(team.agents)
        learners[team.name].observe(
            Transition(
                obs=obs[agents],
                actions=acts[team.name],
                rewards=nxt.rewards[agents],
                next_obs=nxt.obs[agents],
                done=nxt.done,
                truncated=nxt.truncated,
                active=nxt.active[agents],
            )
        )
    return nxt

def fake_play_episode(calls):
    """Resets the world it is given; scores 1 on odd seeds, length = seed mod 4."""

    def play_episode(world, policies, seed, *, trace=False):
        world.reset(seed)
        calls.append((seed, sorted(policies)))
