| 10 | `hierarchical_rp` | portfolios.hrp | Estimate, Spectrum, RunConfig → Portfolio | single-linkage clusters on residual-correlation distance; recursive bisection by inverse cluster variance; capped weights redistributed within their branch | PORT-01, PORT-04, PORT-06 |

### Entry sketch (pre-build — removed by spine task)
```python
def run_rebalance(window: Window, config: RunConfig) -> tuple[Spectrum, list[Estimate], list[Portfolio]]:
    spec = spectrum(window)
    spec = residualize(window, spec)
    estimates = [sample_cov(window), shrink_cov(window), denoise_cov(window, spec)] + factor_cov(window, spec, config)
    estimates = check_estimates(estimates)
    portfolios = min_variance(estimates, config) + risk_parity(estimates, config) + hierarchical_rp(estimates, spec, config)
    return spec, estimates, portfolios + baselines(window, estimates)
```

| ID | Pipeline | Trigger | Steps |
|---|---|---|---|
| **PL-18** | Walk-forward run (part of PL-17) | `qrisk run --config two-year \| one-year \| top100` | open_loader → build_windows → run_rebalances (PL-19 per window, in date order) → hold_months → score_estimators → split_regimes → test_significance (null-hypothesis-testing skill, Holm across all comparisons) → store_results |
| **PL-19** | One rebalance | `qrisk rebalance <date>`; also called by PL-18 and PL-20 | spectrum → residualize (RF-01's method, refit per window) → sample, shrinkage, denoised and factor covariances (k and k = 1) → check_estimates → min_variance, risk_parity and hierarchical_rp on each estimate → baselines |
| **PL-20** | Known-answer bench | `qrisk bench --seed N` | planted_panels (3-factor, noise, two-block) → panel_windows → rebalance_panels (PL-19 as built) → check_answers |
| **PL-21** | Variance report | `qrisk report <run_id> [--also <run_id>]` | load_runs → render_report (dataviz skill) |

**Planned layout:** `packages/qrisk/src/qrisk/` with `walk/`, `structure/`, `estimators/`, `portfolios/` (including a shared `constraints.py`), `evaluate/`, `synth/`, `report/` and `core/`.
