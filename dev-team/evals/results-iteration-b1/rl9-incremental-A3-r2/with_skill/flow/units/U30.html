44	### agents.DQNAgent: Neural value learner
45	`class DQNAgent(Agent): def __init__(self, team: TeamSpec, params: AgentParams, exploration: Exploration, *, seed: int, ablation: Literal["none", "no_memory", "no_target"] = "none")`
46	- **Invariants:** single-agent (batches of 1). The network's input is `team.obs_shape` and its outputs `team.actions.n`. AGENT-03–AGENT-05 and AD-05. With `ablation="no_memory"`, each update uses only the latest transition (ABL-01). With `ablation="no_target"`, targets come from the online network (ABL-02). `ablation` takes `RunSettings.ablation`'s DQN values. No updates happen before `learn_start` transitions. The checkpoint is a PyTorch state dict.
47	- **Errors:** `ValueError` if `team.n_agents != 1`, `team.actions.kind != "discrete"`, or `net="cnn"` and `team.obs_shape` is not 3-D
