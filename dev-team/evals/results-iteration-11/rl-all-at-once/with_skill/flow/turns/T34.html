### AD-22: A component may import the step owners its pipelines call
**Status:** Proposed · **Date:** 2026-10-18 · **Scope:** system
- **Context:** Writing the import-linter contracts from the Components table showed that the table forbids eight imports the Approved pipelines make: PL-01's `run_train` calls `signoff.may_start` and `train_dqn` calls `worlds.make` (learners → signoff, worlds); PL-02 loads the random and scripted agents (evaluate → baselines); PL-03 builds the world for SB3 (reference → worlds); PL-04 rebuilds the world and the baselines to record them (replay → worlds, baselines); PL-08 does both of PL-01's (coevo → worlds, signoff). The contract's Used by lines add three more: `signoff` reads `evaluate.Comparison` and `replay.Recording` for the note, and `reference` trains from `learners.TrainSettings` and returns `learners.RunRecord` (signoff → evaluate, replay; reference → learners). With the table as it stood, M1-T03, M1-T05, M1-T15, M1-T17, M1-T19 and M1-T20 would fail CR-24. The user chose to add the eight imports (UR-49) and the three (UR-53).
- **Decision:** The Components table's Depends on adds learners → worlds, signoff; evaluate → baselines; replay → worlds, baselines; reference → worlds, learners; coevo → worlds, signoff; signoff → evaluate, replay. Every edge still points down: `core` imports nothing first-party, no cycle forms, `worlds`, `baselines` and `store` import no component that trains, evaluates or replays, and nothing imports `coevo` or `reference`. AD-01's rule that only `reference` imports SB3 and Gymnasium is unchanged.
- **Alternatives:** Pass the world and the gate in as arguments from `__main__` — every entry function would take an `Env` factory and a gate callback no caller varies, the config-driven wiring CR-11 rules out. Move `make` into `core` — `core` would then hold the three worlds' rules.
- **Consequences:** The import contracts allow these eleven imports and still forbid every other one the table doesn't list. Tests of `learners` and `replay` use the `worlds.make` fake and registered test worlds (AD-17), not the real worlds, until the system tasks.
