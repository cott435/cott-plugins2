# RL Lab — Spec

**Status:** Approved · **Last updated:** 2026-10-18 · **Brief:** [brief.md](brief.md)

## Summary
A lab of three small 2D worlds (Snake, a fish tank, and predator & prey in that tank), each with a learning method written by hand. Every agent is checked against a hand-written player and a trusted reference implementation of the same method, on games it never trained on. Every run is saved with its settings, learning curve and trained agent, so it can be replayed and compared. Why: see the [brief](brief.md).

## Users
| User | What they need to do |
|---|---|
| Me (the learner) | Train an agent in a world, check whether it really learned, watch it play next to its learning curve, and compare runs to see what a change did |

## Scope
**In scope:** Snake world, value learner, fair evaluation, run log, replays (S1); fish tank world, policy learner (S2); predator & prey world, both sides learning at once, training against past opponents (S3).

**Out of scope:**
- Learning from screen pixels. Agents get positions and distances.
- Evolving populations of agents.
- 3D worlds or physics engines.
- A public demo or web app. Replays are for me.
- Fish competing in the tank. They share one brain, and competition waits for predator and prey.
- A ladder of learning methods on Snake (an optional detour with no stage yet).
- Rented computing beyond the limit in QR-02.

## Features

### Snake world (`SNAKE`)
**Serves:** Goal 2
**Stage:** S1
**Behavior:** Classic Snake on a grid. The snake moves one cell per step, eats food to grow, and dies when it hits a wall or itself. The agent sees positions and distances, never the screen.

**Requirements**
- **SNAKE-01** The world is a flat 2D 12 × 12 grid bounded by walls.
  - Given a new game, when it starts, then the grid is 12 × 12 cells and the snake is 3 cells long.
- **SNAKE-02** Exactly one piece of food is on the grid at a time, on a cell the snake does not occupy.
  - Given a game in progress, when any step ends, then exactly 1 food is on the grid and it is not under the snake.
- **SNAKE-03** Eating food grows the snake by one cell.
  - Given the snake's head moves onto the food, when the step ends, then the snake is 1 cell longer and new food has appeared on a free cell.
- **SNAKE-04** Each step the agent picks one of three moves: turn left, go straight, or turn right.
  - Given any game state, when the agent asks for its allowed moves, then it gets exactly these 3.
**Behavior:** Each trained agent, the world's hand-written player, and the reference (if there is one) play the same 200 games, none of which any of them trained on. The checks give each comparison a pass or fail, so I know whether a result is real learning or luck.

**Requirements**
- **EVAL-01** An evaluation plays 200 games on seeds no compared player trained on, and every player compared plays the same 200.
  - Given an agent, the hand-written player and the reference, when they are evaluated, then each plays the same 200 seeds.
- **EVAL-02** An evaluation reports each player's mean score and spread.
  - Given a finished evaluation, when its report is read, then it shows the mean, the standard deviation and the per-game scores for every player.
- **EVAL-03** "Clearly beats" is tested with the `null-hypothesis-testing` skill. It is given the paired per-game scores of the agent and the hand-written player on the same 200 unseen games. It passes only if the agent's mean is ≥ 1.5× the hand-written player's and the difference is significant at 5%.
  - Given agent mean 12.0 and player mean 7.0, significant at 5%, when checked, then the verdict is "pass".
  - Given agent mean 10.0 and player mean 7.0 (below 1.5×), when checked, then the verdict is "fail", whatever the significance.
- **EVAL-04** "Close to the library" passes only if the hand-written learner's mean score is ≥ 90% of the reference's on the same 200 unseen games, both trained with the same time budget.
  - Given hand-written mean 9.2 and reference mean 10.0, when checked, then the verdict is "pass" (92%).
  - Given hand-written mean 8.5 and reference mean 10.0, when checked, then the verdict is "fail" (85%).
- **EVAL-05** Each verdict is saved with the run it judges, along with the numbers behind it.
  - Given a judged run, when it is opened later, then its verdicts, means, ratio and significance are shown.


**Edge cases & errors**
- The policy collapses to nearly fixed choices early in training → the run's randomness signal (RUNS-03) shows it, and the run continues unless it diverges.
- The policy learner diverges → as VALUE's divergence edge case.

### Predator & prey world (`PREY`)
**Serves:** Goal 2, Goal 3
**Stage:** S3
**Behavior:** The fish tank, with no ball. 6 prey eat food pellets while 1 predator hunts them. Both sides see only nearby things.

**Requirements**
- **PREY-01** The world is the fish tank (TANK-01, TANK-04, TANK-05, TANK-10) with no ball, and with the predator and pellets added.
  - Given a new predator & prey episode, when it starts, then the tank is the same circle with no ball.
- **PREY-02** Each episode has 1 predator and 6 prey at random starting positions, with the predator at least a quarter-radius from every prey.
  - Given a new episode, when it starts, then there is 1 predator and there are 6 prey.
- **PREY-03** 10 food pellets are in the tank at all times. A pellet a prey touches is eaten and reappears at a random spot.
- The pool is empty at the start of a fresh run → the first copy of each side is saved before the first episode, so there is always an opponent.

## Data requirements
- **DATA-01** All experience comes from the worlds themselves, and no outside data is used.
  - Given any run, when its inputs are listed, then they are only the world settings, the seed and the learner settings.
- **DATA-02** Evaluation seeds never overlap training seeds.
  - Given a run's training seeds, when an evaluation draws its 200 seeds, then none is among them.

## Quality requirements
- **QR-01** Each world's main training run finishes within 1 hour (60 minutes) on the laptop's CPU.
  - Checked from the duration in the run log (RUNS-01) of the run each stage's verdicts come from.
- **QR-02** Rented computing costs ≤ $5 per world in total.
  - Checked against the bill for the stage. A world that would need more is a decision to bring back to me.

## Assumptions
1. Each learner is built from basic array and gradient operations. The reference implementation is only used to compare results.
2. Every run records the learner's internal signals over time, so I can work out why a run failed.
3. "Both at once" or "past opponents" is a setting on each run, and "both at once" is the default.
4. A frozen copy of each side is saved every so often, up to 20 copies, and each episode faces a randomly chosen one.
5. Rerunning with the same settings and seed on the laptop gives the same learning curve.
6. Each world trains in ≤ 60 minutes on the laptop CPU, rented computing is capped at $5 per world, and no outside data is used.
