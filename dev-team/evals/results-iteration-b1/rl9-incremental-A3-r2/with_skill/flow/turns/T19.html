### core.Agent: type
```python
class Agent(Protocol):
    def act(self, obs: np.ndarray, *, explore: bool) -> np.ndarray: ...
    def learn(self, t: Transition) -> None: ...
    def save(self, path: Path) -> None: ...
    def load(self, path: Path) -> None: ...
```

- **Invariants:** one agent acts for one team: `act` takes that team's `(n_agents, *obs_shape)` and returns one action per agent, shaped by the team's `ActionSpace`. `explore=False` never samples or takes a random action (AGENT-07): value learners take the best-valued action and policy learners the policy's mean.
