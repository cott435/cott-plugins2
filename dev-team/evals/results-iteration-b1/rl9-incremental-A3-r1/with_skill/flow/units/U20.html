89	### AD-03: Own environment protocol, shaped like Gymnasium
90	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** `core`
91	- **Context:** CORE-01 needs one interface for every environment. REF-01 needs the library agent to train on the same Snake. AGENT-06 keeps library code out of the lab's agents.
92	- **Decision:** `core.Env` is a small Protocol whose `reset(seed)` returns `(obs, info)` and whose `step(actions)` returns a `StepResult` with Gymnasium's fields (observation, reward, terminated, truncated, info), plus `frame()` for replay. AD-09 sets their batch-first shape over agents. `reference` wraps one single-agent team of a `core.Env`, with every other team played by a frozen agent (AD-15), in a `gymnasium.Env` adapter.
93	- **Alternatives:** Subclass `gymnasium.Env` directly — no adapter, but every environment and the core then depend on Gymnasium. A bespoke interface unlike Gymnasium's — needs a bigger adapter and teaches a nonstandard shape.
94	- **Consequences:** Truncation (starvation or the step cap) and termination (a collision or a catch) stay separate, so learning targets bootstrap correctly on truncation. The adapter is checked with Stable-Baselines3's `check_env`.

97	### AD-04: Stable-Baselines3 DQN as the reference implementation
98	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** `reference`
99	- **Context:** For Snake, REF-01–REF-03 need an established implementation trained with the same view, rewards, step budget and seeds as the compact-view neural agent; AD-10 covers the tank. The Stable-Baselines3 DQN docs (https://stable-baselines3.readthedocs.io/en/master/modules/dqn.html, read 2026-10-17) say it supports Discrete actions and Box observations, has `buffer_size`, `target_update_interval`, `exploration_fraction`, `seed` and `device`, and offers `MlpPolicy` for vector observations. The custom-environment guide (https://stable-baselines3.readthedocs.io/en/master/guide/custom_env.html, read 2026-10-17) requires a `gymnasium.Env` with `reset(seed, options) → (obs, info)` and a five-field `step`, checked by `check_env`.
100	- **Decision:** `reference` trains Stable-Baselines3 DQN with `MlpPolicy` on the compact view through the AD-03 adapter, with `device="cpu"`. Its hidden layers, learning rate, discount, batch size, memory size, target interval and exploration schedule are mapped one-to-one from the same `RunSettings` the hand-written agent uses. Its curve points come from `evaluate`, exactly as the lab's own agents' do.
101	- **Alternatives:** CleanRL's single-file DQN — very readable, but a script to copy rather than a library to call, so "matching" it blurs into copying it. RLlib — far heavier than one laptop needs.
102	- **Consequences:** Stable-Baselines3 measures exploration as a fraction of training rather than in decay steps, and updates every `train_freq` steps. The mapping fixes `train_freq=1` and `gradient_steps=1`, and sets `exploration_fraction = decay_steps / steps`. Stable-Baselines3 and Gymnasium are an optional install extra, so the rest of the lab never carries them.
103	- **Probe:** none — the two pages above settle the spaces, parameters and environment interface. No account or plan is involved.

_TRAIN_SEEDS = 1_000_000  # training games draw seeds below the held-out evaluation seeds


def train_reference(settings: RunSettings, *, root: Path = Path("runs")) -> RunRecord:
    """Train Stable-Baselines3 on `settings` with `device="cpu"`, into a run folder."""
    _check_supported(settings)
    writer = create_run(settings, root=root)
    adapter = OneLearnerAdapter(_make_env(settings))
    model = DQN("MlpPolicy", adapter, **dqn_kwargs(settings))
    model.learn(total_timesteps=settings.steps, callback=_CurveCallback(writer, settings, adapter))
    writer.save_checkpoint(ModelPlayer(model))
    return writer.finish("complete")


def _check_supported(settings: RunSettings) -> None:
    if settings.agent != "reference":
        raise ValueError(f"agent: train_reference needs 'reference', got {settings.agent!r}")
    if settings.env != "snake" or settings.view != "compact":
        raise ValueError(
            f"train_reference trains Snake with the compact view, got {settings.env!r} "
            f"with {settings.view!r}"
        )


def _make_env(settings: RunSettings) -> Env:
    return Snake(view="compact", rewards=settings.rewards)


def dqn_kwargs(settings: RunSettings) -> dict[str, Any]:
    """The one-to-one mapping from the hand-written DQN's settings to Stable-Baselines3 (AD-04)."""
    p, e = settings.params, settings.exploration
    return {
        "learning_rate": p.lr,
        "gamma": p.gamma,
        "batch_size": p.batch_size,
        "buffer_size": p.memory_size,
        "target_update_interval": p.target_every,
        "learning_starts": p.learn_start,
        "exploration_initial_eps": e.start,
        "exploration_final_eps": e.end,
        "exploration_fraction": min(1.0, e.decay_steps / settings.steps),
        "train_freq": 1,
        "gradient_steps": 1,
        "policy_kwargs": {"net_arch": [p.hidden, p.hidden]},
        "seed": settings.seed,
        "device": "cpu",
        "verbose": 0,
    }


class OneLearnerAdapter(gym.Env[np.ndarray, np.int64]):
    """The single agent of a one-team `core.Env` as a `gymnasium.Env` (AD-03)."""

    def __init__(self, env: Env) -> None:
        team = env.teams[SOLO]
        self._env = env
        self.observation_space = gym.spaces.Box(-np.inf, np.inf, team.obs_shape, np.float32)
        self.action_space = gym.spaces.Discrete(team.actions.n)
        self.games = 0

    def reset(
        self, *, seed: int | None = None, options: dict[str, Any] | None = None
    ) -> tuple[np.ndarray, dict[str, Any]]:
        super().reset(seed=seed)
        obs, info = self._env.reset(int(self.np_random.integers(_TRAIN_SEEDS)))
        return obs[SOLO][0], dict(info)

    def step(self, action: np.int64) -> tuple[np.ndarray, SupportsFloat, bool, bool, dict[str, Any]]:
        result = self._env.step({SOLO: np.array([action], dtype=np.int64)})
        if result.terminated or result.truncated:
            self.games += 1
        reward = float(result.reward[SOLO][0])
        return result.obs[SOLO][0], reward, result.terminated, result.truncated, dict(result.info)


class ModelPlayer:
    """The model in training as a `core.Agent`: greedy unless exploring; it learns only in SB3."""

    def __init__(self, model: BaseAlgorithm) -> None:
        self._model = model

    def act(self, obs: np.ndarray, *, explore: bool) -> np.ndarray:
        actions, _ = self._model.predict(obs, deterministic=not explore)
        return np.asarray(actions, dtype=np.int64)

    def learn(self, t: Transition) -> None:
        raise RuntimeError("the reference model learns only inside Stable-Baselines3")

    def save(self, path: Path) -> None:
        self._model.save(path)

    def load(self, path: Path) -> None:
        self._model.set_parameters(str(path))


class _CurveCallback(BaseCallback):
    """Adds a curve point from `evaluate.evaluate` at step 0, every `eval_every` and the end."""

    def __init__(self, writer: RunWriter, settings: RunSettings, adapter: OneLearnerAdapter) -> None:
        super().__init__()
        self._writer = writer
        self._settings = settings
        self._adapter = adapter
        self._started = 0.0

    def _on_training_start(self) -> None:
        self._started = time.perf_counter()
        self._add_point()

    def _on_step(self) -> bool:
        if self.num_timesteps % self._settings.eval_every == 0:
            self._add_point()
        return True

    def _on_training_end(self) -> None:
        if self.num_timesteps % self._settings.eval_every:
            self._add_point()

    def _add_point(self) -> None:
        s = self._settings
        scores = evaluate(
            lambda: _make_env(s),
            {SOLO: ModelPlayer(self.model)},
            player=s.name,
            train_seed=s.seed,
            options=EvalOptions(n_games=s.eval_games),
        )
        point = CurvePoint(
            step=self.num_timesteps,
            games=self._adapter.games,
            mean_score=float(np.mean(scores.scores)),
            elapsed_s=time.perf_counter() - self._started,
        )
        self._writer.add_point(point)
