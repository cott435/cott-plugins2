## Strategy
- **PL-18 (study):** TC-40, TC-42, TC-43, TC-44, TC-51.
- **PL-19 (screen):** TC-38, TC-41, TC-45, TC-46, TC-52.
- **PL-20 (models):** TC-48, TC-49, TC-50. TC-49 is the model evaluation.
- **PL-21 (holdout):** TC-39, TC-47.

Each pipeline also has a smoke command (`qlab-features <cmd> --smoke`), unit tests for every step module, and a boundary test consuming `portfolio`'s frozen `Returns`, `Window` and `Structure` samples.

## The oracles
None of these numbers was computed during planning. Each is either a hand-checkable closed form or a property checked when the test runs.

| Case | What it checks | Expected | Tolerance |
|---|---|---|---|
| TC-38 | Splits | First test year after at least 5 training years; no training date within **26** trading days (horizon 21) or **10** (horizon 5) of its test block; no holdout dates | exact |
| TC-39 | Holdout lock | Holdout targets are **NaN** before opening, and a direct read raises `HoldoutReadError`. An unconfirmed opening appends nothing. After one confirmed opening, targets pass through; a **second opening raises** | exact |
| TC-40 | Ledger tamper | Edit entry 3 → `LedgerTamperedError` naming **3**; delete entry 4 → naming **4**; an untouched ledger opens | exact |
| TC-41 | Holm over the ledger | p = 0.001, 0.02, 0.04 → adjusted **0.003, 0.04, 0.04**, all supported. Add 30 entries at p = 0.5 → **0.033, 0.64, 1.0**, only the first still supported | 1e-12 |
| TC-42 | Target | Loadings and factor count at D are **bit-identical** after every later return is redrawn. A known delisting (+15%) enters the target; an unknown one gives **no target** and is counted | exact |
| TC-43 | Feature definitions | momentum **1.001²³¹ − 1**; reversal **1.001²¹ − 1**; volatility = sample standard deviation of the ±1% sequence; beta **1.5**; max return **0.07**; illiquidity **2e-8**; abnormal volume **1**; idiosyncratic volatility **0** | 1e-12 (beta 1e-9) |
| TC-44 | No look-ahead; coverage | Every feature at D is identical after redrawing later data. **50 of 63 days → missing**, 51 → present; ranks lie in [−0.5, 0.5] | exact |
| TC-45 | Screen (`null-hypothesis-testing`) | Planted rank correlation 0.05 over 150 months **passes**; 20 noise features over 20 seeds → **at most 1 seed** has any pass | 5% family-wise, Holm |
| TC-46 | Sub-periods | Signs (+, +, −) → **unstable**, never survivor | exact |
| TC-47 | Holdout failure | A signal that stops at the holdout: walk-forward survivor and ridge beats zero → both **failed** on the holdout, reported as failures, all logged in the ledger | α 0.05 |
| TC-48 | Ridge against reference | Coefficients and intercept match the reference implementation for all 5 penalties | 1e-6 relative |
| TC-49 | Model claims (`null-hypothesis-testing`) | Linear signal → **ridge beats zero**; noise → **no claim**; feature₁ × feature₂ interaction → **trees beat ridge** | 5% family-wise, Holm |
| TC-50 | Grid in the ledger | **24** configuration entries (8 × 3 refits); each refit picks the best inner score; reruns identical | exact |
| TC-51 | Reproducible | Identical study numbers on rerun; the second screen appends 8 tests, and its correction equals a fresh Holm over all **16** | exact |
| TC-52 | Too few months | 30 months → **too_few_months**, logged, never a result | exact |

## Assumptions
- **No trusted pairs, as before.** Real-data verdicts are what the screen finds behind the gate. These cases prove the gate, the definitions and the tests.
- **Generators:** the build writes `planted_feature_panel`, `noise_feature_panel` and `interaction_panel`, and reuses `portfolio`'s `one_factor_panel` and `walk_forward_panel`. Seeds and sizes are in each `input.json`.
- **TC-48's reference** is the test-only ridge from AD-23, with the intercept handled the same way on both sides.
- **TC-41** checks the ledger's Holm arithmetic directly. The statistical procedures themselves (TC-45, TC-46, TC-47, TC-49, TC-52) are routed to `null-hypothesis-testing`.
