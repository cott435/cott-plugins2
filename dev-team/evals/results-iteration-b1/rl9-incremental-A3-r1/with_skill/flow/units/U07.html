137	- **Decision:** Every environment is batch-first over its agents. 466	### AD-03: Own environment protocol, shaped like Gymnasium
467	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** `core`
468	- **Context:** CORE-01 needs one interface for every environment. REF-01 needs the library agent to train on the same Snake. AGENT-06 keeps library code out of the lab's agents.
469	- **Decision:** `core.Env` is a small Protocol whose `reset(seed)` returns `(obs, info)` and whose `step(actions)` returns a `StepResult` with Gymnasium's fields (observation, reward, terminated, truncated, info), plus `frame()` for replay. AD-09 sets their batch-first shape over agents. `reference` wraps one single-agent team of a `core.Env`, with every other team played by a frozen agent (AD-15), in a `gymnasium.Env` adapter.
470	- **Alternatives:** Subclass `gymnasium.Env` directly — no adapter, but every environment and the core then depend on Gymnasium. A bespoke interface unlike Gymnasium's — needs a bigger adapter and teaches a nonstandard shape.
471	- **Consequences:** Truncation (starvation or the step cap) and termination (a collision or a catch) stay separate, so learning targets bootstrap correctly on truncation. The adapter is checked with Stable-Baselines3's `check_env`.

474	### AD-06: One folder per run; TOML settings in, plain files out
475	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** `runs`
476	- **Context:** RUN-01 needs a run fully described by its settings. RUN-02 needs settings, seed, curve, checkpoint and games saved. RUN-05 needs reloading. The interrupted-run edge case needs partial records kept.
477	- **Decision:** Settings are read from TOML into a frozen `core.RunSettings`. Each run writes `runs/<name>-s<seed>-<timestamp>/` holding `settings.json` (the resolved settings), `curve.csv`, `checkpoint.pt` or `checkpoint.npz`, `games.npz` and `status` (`running`, `complete` or `incomplete`).
