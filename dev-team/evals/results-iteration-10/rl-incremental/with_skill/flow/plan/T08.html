requirementBASE-01The random player picks each move uniformly at random from the 3 moves.
criteria
  • Given 30,000 random-player moves, when the share of each move is counted, then each is between 32% and 35%.
requirementBASE-02The scripted bot moves toward the food, never making a move that kills it immediately when a safe move exists.
criteria
  • Given food to the left and the left cell free, when the bot moves, then it turns left.
  • Given food straight ahead and a wall straight ahead with the right cell free, when the bot moves, then it turns right.
  • Given several safe moves equally close to the food, when the bot moves, then it prefers straight, then left, then right.
requirementBASE-03When every move kills it, the scripted bot goes straight.
criteria
  • Given danger straight, left and right, when the bot moves, then it goes straight and the game ends.
featureDQNDQN ladder
stagesS1
stage_viaStage line
source—
servesG1, G3
requirementDQN-01The plain rung learns from each move right after it is made, using that move's reward plus the discounted best score of the next situation as its target.
criteria
  • Given a known function, move, reward and next situation, when one update is applied, then the target equals the hand-computed value and the function's score for that move moves toward it.
requirementDQN-02The replay-buffer rung stores past moves and learns from batches drawn at random from that store.
criteria
  • Given a store of past moves and a seed, when a batch is drawn, then every move in it comes from the store and the same seed draws the same batch.
  • Given a store at its saved capacity, when a new move is added, then the oldest move is dropped.
requirementDQN-03The target-network rung computes its targets from a frozen copy of the learner, refreshed every fixed number of updates saved with the run's settings.
criteria
  • Given the refresh interval, when updates run between two refreshes, then the copy does not change; when the interval is reached, the copy equals the learner.
requirementDQN-04The Double DQN rung chooses the next situation's best move with the learner, and scores that move with the frozen copy.
criteria
  • Given a learner and a copy that disagree on the next situation's best move, when the target is computed, then it uses the copy's score for the learner's chosen move.
requirementDQN-05Each rung differs from the rung before only by the piece it adds; every other setting is the same.
criteria
  • Given the saved settings of two neighbouring rungs, when they are compared, then the only differences are the added piece and its own settings.
requirementDQN-06While training, each rung explores with the same falling random-move rate as TAB-02; during test games it always picks its highest-scored move.
criteria
  • Given a trained rung, when a test game is played twice from the same seed, then both games are identical.
requirementDQN-07The learning updates of every rung are written in the project; no ready-made learning algorithm is used.
criteria
  • Given any trained rung, when its learning steps are traced, then each one is code written in the project.
featureEVALEvaluation & comparison
stagesS1
stage_viaStage line
source—
servesG2, G3
requirementEVAL-01Every agent is scored on the same 100 test games, each started from a fixed test seed that is never used in training.
criteria
  • Given any two agents, when they are tested, then they play games from the same 100 test seeds.
  • Given any training run, when its game seeds are compared with the test seeds, then none match.
requirementEVAL-02An agent's test score is the mean food eaten per game over the 100 test games.
criteria
  • Given 100 test games with known food eaten, when the score is computed, then it equals their mean.
requirementEVAL-03Each run's learning curve is its test score against moves trained, at 20 evenly spaced points, with the random player's and the scripted bot's scores drawn as lines on the same chart; the chart follows the dataviz skill.
criteria
  • Given a finished run, when its curve is opened, then it shows 20 test scores in order of moves trained, plus both baseline lines.
  • Given the 5 seeds of one learner, when their combined curve is opened, then it shows the mean across seeds at each point with the spread across seeds.
requirementEVAL-04Each learner's final agent is compared with each baseline using the null-hypothesis-testing skill. It is given the 100 test-game scores of each of the learner's 5 seed runs, and the baseline's scores on the same 100 games. The learner beats the baseline when its score is higher and the difference is significant at 5% after correcting for the number of comparisons in the report; it ties when the difference is not significant; otherwise it loses.
criteria
  • Given 5 complete seed runs of a learner, when the comparison is made, then the report states beats, ties or loses against each baseline, with the test's result.
  • Given fewer than 5 complete seed runs, when the comparison is requested, then it is not made, and the report lists the missing seeds.
requirementEVAL-05Each added piece gets a before-and-after comparison with the rung below it, made the same way as EVAL-04: table learner → plain DQN, plain → + replay buffer, + replay buffer → + target network, + target network → + Double DQN, and plain reward → shaped reward. Every outcome counts: better, worse, or no difference.
criteria
  • Given 5 complete seed runs of both rungs, when the comparison is made, then the report states better, worse or no difference, with the test's result and both rungs' combined curves on one chart.
requirementEVAL-06Every comparison result holds a written explanation; a result with no explanation is shown as unexplained.
criteria
  • Given a comparison result with an empty explanation, when the report is opened, then that result is marked unexplained.
  • Given a tie or a no-difference result with an explanation, when the report is opened, then it is marked explained.
requirementEVAL-07Snake is done when the Double DQN agent beats the random player, beats or ties the scripted bot, every comparison in EVAL-04 and EVAL-05 has a result, and every tie and no-difference result is explained.
criteria
  • Given a Double DQN agent that beats both baselines and all comparisons made and explained, when the done check runs, then it reports done.
  • Given a Double DQN agent that ties the scripted bot with the tie explained, when the done check runs, then it reports done.
  • Given a tie with the scripted bot left unexplained, when the done check runs, then it reports not done and names the missing explanation.
  • Given a Double DQN agent that ties or loses to the random player, when the done check runs, then it reports not done.

criteria

featureSHAPEReward shaping
stagesS1
stage_viaStage line
source—
servesG1, G3
requirementSHAPE-01The shaped reward is the plain reward plus 0.1 for a move that brings the head closer to the food and minus 0.1 for a move that takes it further away, measured in grid steps to the food that was on the board before the move.
criteria
  • Given a move that cuts the distance to the food from 5 to 4, when it is made, then the shaped reward is +0.1.
  • Given a move that raises the distance from 4 to 5, when it is made, then the shaped reward is −0.1.
  • Given a move that eats the food, when it is made, then the shaped reward is +1.1.
requirementSHAPE-02A move that ends the game by collision has a shaped reward of −1, with no nudge.
criteria
  • Given a move into a wall, when it is made, then the shaped reward is −1.
requirementSHAPE-03Every run uses either the plain or the shaped reward for training, and saves which.
criteria
  • Given a finished run, when its saved settings are read, then they name its reward.
requirementSHAPE-04Test scores never use the shaped reward; they always count food eaten.
criteria
  • Given the same agent tested once after plain training and once after shaped training, when the scores are read, then both are food eaten per game.
requirementSHAPE-05The plain-versus-shaped comparison trains the Double DQN rung on each reward, with every other setting the same.
criteria
  • Given the plain and shaped runs of that comparison, when their saved settings are compared, then the only difference is the reward.
featureSNAKESnake environment
stagesS1
stage_viaStage line
source—
servesG1, G5
requirementSNAKE-01The game is played on a fixed 10×10 board of open cells surrounded by walls.
criteria
  • Given any game, when it starts, then the board has 10×10 open cells, walls on all four sides, a snake of length 3 in the middle row heading right, and exactly one food on an empty cell.
  • Given any training run or test game, when the board size is read, then it is 10×10.
requirementSNAKE-02On each move the agent chooses one of 3 moves relative to its heading: straight, turn left, turn right.
criteria
  • Given a snake heading right, when it turns left, then its head moves up one cell and its heading becomes up.
  • Given any heading, when any of the 3 moves is chosen, then the snake never reverses into its own neck.
requirementSNAKE-03Eating food makes the snake 1 cell longer, gives a reward of +1, and places a new food on an empty cell.
criteria
  • Given food directly ahead, when the snake moves straight, then its length goes up by 1, the move's plain reward is +1, and one new food appears on a cell not covered by the snake.
requirementSNAKE-04Moving into a wall or into the snake's own body ends the game with a reward of −1.
criteria
  • Given the head next to a wall, when the snake moves into the wall, then the game ends and the move's reward is −1.
  • Given the head next to a body cell that will still be occupied after the move, when the snake moves into it, then the game ends and the move's reward is −1.
requirementSNAKE-05Every move that neither eats nor kills has a plain reward of 0.
criteria
  • Given a move into an empty cell, when it is made, then its plain reward is 0.
requirementSNAKE-06At every move the agent sees exactly 11 yes/no facts: danger straight, danger left, danger right; heading up, down, left, right; food is up, down, left, right of the head.
criteria
  • Given the head next to the top wall while heading up, when the facts are read, then "danger straight" is yes and "heading up" is yes.
  • Given food above and to the left of the head, when the facts are read, then "food is up" and "food is left" are yes and "food is down" and "food is right" are no.
  • Given a cell occupied by the body or a wall next to the head on its left, when the facts are read, then "danger left" is yes.
requirementSNAKE-07A game ends after 100 moves in a row without eating.
criteria
  • Given a snake that has gone 100 moves since its last food (or since the start), when the 100th move is made without eating, then the game ends and that move's plain reward is 0.
requirementSNAKE-08The same game seed and the same moves always give the same game.
criteria
  • Given a game seed and a list of moves, when the game is played twice, then every board, food position, reward and ending is identical.
featureTABTable-based Q-learning
stagesS1
stage_viaStage line
source—
servesG1
requirementTAB-01The table learner updates the score of the move it just made from the reward plus the discounted best score of the situation it reached (a one-step Q-learning update), after every move.
criteria
  • Given a known table, situation, move, reward and next situation, when one update is applied, then the new score equals the hand-computed Q-learning update for the run's learning rate and discount.
  • Given a move that ended the game, when the update is applied, then the next situation contributes nothing.
requirementTAB-02While training, the table learner sometimes picks a random move instead of its best one, at a rate that falls over the run from a starting rate to a floor saved with the run's settings.
criteria
  • Given a run's exploration settings, when the rate is read at the start, the middle and the end of training, then it matches the saved schedule at each point.
requirementTAB-03During test games the table learner always picks its highest-scored move.
criteria
  • Given a trained table, when a test game is played twice from the same seed, then both games are identical.
requirementTAB-04The learning update is written in the project; no ready-made learning algorithm is used.
criteria
  • Given the trained table learner, when its learning steps are traced, then each one is code written in the project.
