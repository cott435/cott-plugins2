# qrisk — Contract

**Package:** qrisk · **Status:** Draft · **Last updated:** 2026-10-17 · **Architecture:** [architecture.md](architecture.md)

Everything below is importable from `qrisk` itself. Matrices are `numpy.ndarray` (float64) indexed by the window's `ids` order; frames are pandas DataFrames checked against the named pandera schema.

### qrisk.RunConfig: type
`@dataclass(frozen=True) class RunConfig: window: int = 504; min_obs: int = 499; universe: Literal["sp500", "top100_traded_value"] = "sp500"; cap: float = 0.05; max_factors: int = 20; corr_horizon: int = 126; crises: tuple[tuple[date, date], ...] = ((date(2007, 10, 1), date(2009, 6, 30)), (date(2020, 2, 19), date(2020, 6, 30))); seed: int = 0`
- **Invariants:** the one-year configuration is `window=252, min_obs=247` (WALK-05); `min_obs ≤ window`; a run's results name the config and the snapshot ID
- **Boundary:** walk, evaluate, report · **Fixtures:** tests/contracts/qrisk.RunConfig/ · **Cases:** two-year default, one-year, top-100 fallback
- **Used by:** walk, evaluate, report, the CLI

### qrisk.Window: type
`@dataclass(frozen=True) class Window: rebalance: date; ids: tuple[SecurityId, ...]; returns: DataFrame  # trading days × ids, total returns, gaps filled with 0; excluded: int; zero_filled: int`
- **Invariants:** `returns` has exactly `RunConfig.window` rows, all strictly before `rebalance` (WALK-03); `ids` sorted, every one a member at the previous close with ≥ `min_obs` returns (WALK-02, WALK-04); no column has zero variance (STRUC edge case)
- **Boundary:** structure, estimators, portfolios · **Fixtures:** tests/contracts/qrisk.Window/ · **Cases:** a 504 × 500 planted 3-factor window, a 252 × 400 window, a window with 5 zero-filled days
- **Used by:** walk, structure, estimators, portfolios

### qrisk.Spectrum: type
`@dataclass(frozen=True) class Spectrum: rebalance: date; eigenvalues: ndarray; edge: float; n_above: int; explained: ndarray; loadings: ndarray; raw_offdiag: float; residual_offdiag: float; residual_corr: ndarray`
- **Invariants:** `eigenvalues` descending; `edge` is the Marchenko–Pastur upper edge for N/T of the window; `explained` and `loadings` have `n_above` columns; `residual_corr` is the N × N correlation of returns after removing those factors, on standardised returns throughout
- **Boundary:** estimators, portfolios · **Fixtures:** tests/contracts/qrisk.Spectrum/ · **Cases:** planted 3 factors, pure noise (`n_above` 0), one-factor panel
- **Used by:** structure, estimators, portfolios, walk

### qrisk.Estimate: type
`@dataclass(frozen=True) class Estimate: name: Literal["sample", "shrinkage", "denoised", "factor_k", "factor_1"]; ids: tuple[SecurityId, ...]; cov: ndarray | None; params: Mapping[str, float]; failed: str | None`
- **Invariants:** `cov` is symmetric, PSD and finite, or `None` with `failed` naming why (COV-05); `params` holds the shrinkage intensity or k
- **Boundary:** portfolios, evaluate · **Fixtures:** tests/contracts/qrisk.Estimate/ · **Cases:** each of the five names on the planted window, one failed with a negative eigenvalue
- **Used by:** estimators, portfolios, evaluate, walk

### qrisk.Portfolio: type
`@dataclass(frozen=True) class Portfolio: method: Literal["min_var", "risk_parity", "hrp", "equal_weight", "sample_min_var"]; estimator: str | None; ids: tuple[SecurityId, ...]; weights: ndarray | None; predicted_var: float | None; failed: str | None`
- **Invariants:** weights ≥ 0, ≤ cap, summing to 1 within 1e-8 (PORT-01), or `None` with `failed` set (PORT-06); `estimator` is `None` only for `equal_weight`
- **Boundary:** evaluate · **Fixtures:** tests/contracts/qrisk.Portfolio/ · **Cases:** min-var with binding caps, risk parity uncapped, HRP on two blocks, equal weight over 400, a failed construction
- **Used by:** portfolios, evaluate, walk

### qrisk.MonthResult: type
`MonthResult = DataFrame[MonthSchema]  # rebalance, method, estimator, realized_var, predicted_var, bias_ratio, corr_error, regime ("crisis" | "calm"), n_eligible, failed`
- **Invariants:** one row per rebalance × portfolio (and per estimator for `corr_error`); `realized_var` = 252 × sample variance of the month's daily returns with drifting weights (EVAL-01, WALK-06); `corr_error` NaN where fewer than `corr_horizon` days remain (EVAL-02)
- **Boundary:** evaluate, report · **Fixtures:** tests/contracts/qrisk.MonthResult/ · **Cases:** three months across a crisis boundary, a month with a mid-month delisting, a failed portfolio
- **Used by:** walk, evaluate, report

### qrisk.TestResult: type
`@dataclass(frozen=True) class TestResult: candidate: str; baseline: str; regime: Literal["all", "crisis", "calm"]; n_months: int; statistic: float; p_value: float; p_adjusted: float; rejects: bool; procedure: str`
- **Invariants:** `p_adjusted` is Holm-corrected across every comparison in the run; `rejects` is `p_adjusted < 0.05` (EVAL-04); `procedure` names what the `null-hypothesis-testing` skill ran
- **Boundary:** report · **Fixtures:** tests/contracts/qrisk.TestResult/ · **Cases:** a rejected and a non-rejected comparison
- **Used by:** evaluate, report

### qrisk.Panel: type
`@dataclass(frozen=True) class Panel: returns: DataFrame; true_cov: ndarray; n_factors: int; seed: int`
- **Invariants:** generated at N = 500, T = 504 unless told otherwise; the same seed gives an identical panel (SYNTH-01); `n_factors` 0 for pure noise
- **Boundary:** structure, estimators, portfolios · **Fixtures:** tests/contracts/qrisk.Panel/ · **Cases:** 3 planted factors, pure noise, two uncorrelated blocks
- **Used by:** synth, structure, estimators, portfolios

### qrisk.RunResult: type
`@dataclass(frozen=True) class RunResult: run_id: str; snapshot_id: str; config: RunConfig; path: Path; months: int; skipped: tuple[date, ...]`
- **Invariants:** `path` is `research/<run_id>/` under the data root; `skipped` lists rebalances with fewer than 1/cap eligible members
- **Boundary:** the CLI · **Fixtures:** tests/contracts/qrisk.RunResult/ · **Cases:** a synthetic two-year run
- **Used by:** walk, report, the CLI

### qrisk.run_walk_forward: Walk-forward run
`def run_walk_forward(loader: Loader, config: RunConfig = RunConfig()) -> RunResult`
- **Invariants:** reads only through `loader`; rebalances on the first trading day of each month from the first full window to the last complete month (WALK-01); ≤ 30 min for one configuration on the real snapshot (QR-12)
- **Errors:** `WindowTooShortError` naming the shortfall when the snapshot can't hold one window plus one month
- **Used by:** the CLI, research code

### qrisk.build_report: Variance report
`def build_report(result: RunResult, also: Sequence[RunResult] = ()) -> Path`
- **Invariants:** one self-contained HTML file naming the snapshot and configurations, with VREP-01's sections; `also` adds the one-year run beside the two-year one (EVAL-06); same inputs → identical tables (VREP-02)
- **Used by:** the CLI

| Component | Covers | Responsibility |

| `portfolios` | PORT-01 to PORT-06 | Minimum variance, risk parity, HRP on the residual correlation, and the two baselines, under the shared 5% rules |
| `evaluate` | EVAL-01 to EVAL-06 | Out-of-sample variance, correlation error, bias ratio, regimes, and the null-hypothesis-testing skill |
| `synth` | SYNTH-01 to SYNTH-04 | Seeded planted and noise panels with their true covariance |

**The contract has 9 types and 2 functions:**
- **Types:** `RunConfig` (defaults for the two-year run; variants for one-year and top-100), `Window`, `Spectrum`, `Estimate`, `Portfolio`, `MonthResult`, `TestResult`, `SynthPanel` and `RunResult`.
- **Functions:** `run_walk_forward` and `build_report`.

**Root doc (now Draft):**
- `qrisk` is added to the system map.
- New dependency rule: `qrisk` imports only `qdata`'s public names, never `qops`, `server` or a network client, and nothing imports `qrisk`.
- New system pipeline: **PL-17 Variance walk-forward**, `qrisk` → `qdata.Loader`.

**New decisions, all Proposed:**
- **AD-17:** the separate read-only research package.
- **AD-18:** **cvxpy with Clarabel** solves minimum variance as a quadratic program. Risk parity uses the convex log-barrier form: names that hit the cap are fixed at it and the rest re-solved.
- **AD-19:** shrinkage, denoising, the factor model and HRP are **written by hand** on numpy and scipy. **PyPortfolioOpt is a test-only reference**; scikit-learn's Ledoit–Wolf was rejected because it shrinks toward the wrong target.
- **AD-20:** the significance procedure belongs to the null-hypothesis-testing skill, using scipy only; Holm correction runs across every comparison.

**Two new risks:**
- The sample covariance may fail often in the one-year configuration. Failures are counted, and the top-100 fallback exists if they dominate.
- QR-12's runtime is an estimate (about 11 minutes of solves) until a real run measures it.

**Probes:** none needed, since no decision depends on an outside service.

## Assumptions

- **Names:** the package is called `qrisk`, and its CLI is `qrisk run --config two-year | one-year | top100` plus `qrisk report`.
- **Results location:** results go to `research/<run_id>/` under the data root. Covariance matrices aren't stored; they're recomputed from the snapshot, which is how reruns stay identical.
- **Speed:** rebalances run in a process pool, with results ordered by date.
- **No changes elsewhere:** `qdata`, `qops`, `server` and `cockpit` are untouched.
