### RF-01: PCA market-mode removal
**File:** `references/market_decomposition.py` · **Hash:** b3993e95 · **Kind:** code · **Milestones:** S2
- **Purpose:** removes the dominant principal components (the market mode) from a daily returns panel, leaving residual returns
- **Key parts:** `pca_factors(returns, k)`, `residualize(returns, factors)`, `remove_market(returns, k)`, `residual_correlation_check(residuals)`, `demean_returns(returns, min_obs)`
- **In → Out:** T×N simple daily returns (dates × tickers) → residuals (T×N), factors (T×k), loadings and betas (N×k), explained variance (k)
- **Use for:** the market-factor removal step and the residual returns later tested against; a "mean absolute correlation drops after removal" check
- **Caveats:** fits means, scales, eigenvectors and betas on the whole panel (look-ahead), so the project must fit per window; silently drops columns with under 60 rows and fills gaps with 0 returns; no random-matrix denoising; no error handling (k > N, empty panel)

### RF-02: Sequence-model window builder
**File:** `references/tft_dataset.py` · **Hash:** fdf31b69 · **Kind:** code · **Milestones:** S4
- **Purpose:** turns a long (ticker, date) panel into lookback/horizon training windows for a temporal-fusion-transformer-style forecaster, with static, known-in-advance and observed inputs kept apart
- **Key parts:** `WindowSpec`, `add_calendar_features(panel)`, `encode_static(panel, cols)`, `normalise_observed(panel, cols, window)`, `build_windows(panel, targets, spec)`, `split_by_origin(arrays, train_end, valid_end)`
- **In → Out:** feature panel + targets keyed on (ticker, date) → arrays static (S×n), known (S×(L+H)×n), observed (S×L×n), target (S×H×n), origin, ticker; split train/valid/test by origin date
- **Use for:** the windowing and dataset step of the neural forecasting stage; a test that observed inputs never pass the origin date
- **Caveats:** `split_by_origin` has no purge or embargo, so overlapping labels leak across splits; `encode_static` builds its vocabulary on the full sample and fails on unseen categories; inner merge and short-ticker skips drop rows silently (survivorship risk); windows can span date gaps; no exchange holiday calendar; stride-1 copies are memory-heavy
