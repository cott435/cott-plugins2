# RL Lab — Architecture

**Status:** Approved · **Shape:** Single package · **Last updated:** 2026-10-18 · **Spec:** [spec.md](spec.md)

## Overview
One Python package, `rllab`. Every environment and every agent sits behind the protocols in `core`. The training loop, evaluation, run records, curves and replay viewer use only those protocols, so they never import Snake. A training run plays seeded games with a hand-written DQN agent. Every 50 games it scores the agent greedily on 100 held-out seeds, and it rewrites its JSON record after each of those checks. The study command trains the full agent and its 3 ablations, 5 seeds each, scores both baselines, and runs the `null-hypothesis-testing` comparisons. It then writes a report and a chart for the learner's notes page. Charts are drawn only from saved records. A replay re-plays a saved agent on a seed, so it never depends on frames saved during training.

- **Alternatives:** Failing the whole study on any stopped full-agent run: breaks the EVAL edge case and loses hours of finished runs (QR-02). Comparing an ablation on its finished seeds too: the ABL edge case says missing, and fewer ablation seeds weaken a "no detectable difference" verdict without saying so.
- **Consequences:** A study with a stopped full-agent run still compares, with less power, and the report says how many seeds were used. Pairing per game on seed means matches TC-08's test, so the `null-hypothesis-testing` design holds.

## Risks and open questions
- **Training time (QR-01, QR-02):** 1,000 training games and the evaluation every 50 games (20 × 100 greedy games) haven't been timed. A greedy agent that circles until the step limit makes evaluation games long. Mitigation: the first build milestone times one run alone and three in parallel. If too slow, lower the default game count; the spec doesn't fix it.
- **Settings the spec leaves open:** network 11 → 256 → 3, Adam lr 1e-3, batch 64, Huber loss, one update per step and linear ε decay are tutorial defaults, not tested here (AD-02). If the full agent doesn't beat the scripted baseline (EVAL-04), tune these before questioning the design.
- **Comparison method:** the test statistic, how the 5 seeds × 100 games are paired and the multiple-comparison correction are left to the `null-hypothesis-testing` skill when `study.compare_scores` is built. The contract passes it the raw per-seed, per-game scores so the skill can pair by game seed; each side may have fewer than 5 seeds (AD-09).
