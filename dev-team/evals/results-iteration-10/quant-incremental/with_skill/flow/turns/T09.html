# New: a probe is written

`probes_unwritten` lists a probe a decision cites with no entry yet (`PB-01 (AD-04)`), or the user asks a question about a service ("does the weather API return hourly history back to 2015?"). Use the shape in `entry.md` and the rules in `safety.md`. `../examples.md` shows the whole round for FinTrack's Plaid probe.

## 1. Read what the probe serves

- The decision and its Risks line (`dt section AD-04`), the requirements it rests on, and the contract types whose fields depend on the source. A user's direct question informs the decision being made. With no decision yet, ask which requirement it serves; a probe that informs nothing isn't written.
- The vendor's **official docs**: one page per question (the pricing or plan page, the endpoint reference, the error and rate-limit pages, the sandbox page), never a homepage or a third-party summary. Note each with the date read. A page that refuses a fetch is named under Open questions, not guessed at.

## 2. Sort every claim the decision rests on

| The claim | Goes to |
|---|---|
| The docs settle it | Docs read, cited; no check |
| The docs are silent, vague ("up to 24 months"), or contradict the design | A check |
| It depends on the user's account, plan, institutions or data | A user check |
| The user gave test facts: known cases the source must hold (GridLoad's ten decommissioned meters, which history must still include) | One check covering every listed case, by count ("10 of 10 have readings"). The list goes in the script, or in `out/` when it is private |

A contradiction between the docs and the decision (the weather API's timestamps are UTC, and the decision says local time) goes to the gate summary at once, as a hand-off to architecture-design, before anything runs.

## 3. Write the entry

Draft, with the checks table. Each check's Pass comes from the requirement it informs, with the ID in the cell ("≥ 12 months where the bank keeps it (DATA-01)"). Order the checks so the cheap ones come first and a failure stops the run before anything is spent. Spends names everything a run uses up.

## 4. Write the folder

1. Copy `templates/probe_kit.py` unchanged, and `templates/README.md` and `templates/.env.example`; fill both in, the README's order across probes included (`entry.md`).
2. Write `public.py` for the agent's checks, if any, and `probe.py` for the user's, ending in `run()`. Each check is one function ending in `record()`. Allow-list every field that reaches evidence.
3. Add the `.gitignore` lines from `safety.md` that are missing.
4. `dt probes --stamp PB-NN` writes the Hash.

## 5. Run the agent's checks

`env -i PATH="$PATH" python3 probes/PB-NN-<slug>/public.py`, then fill those rows' Result. A scan hit means the allow-list is wrong: fix the script and run again, without opening `out/`. Never run `probe.py`, not even with a dry-run flag.

## 6. Gate

Besides SKILL.md's gate, show:
- **Settled by the docs:** each claim and its page, in one line each.
- **Contradictions** found in step 2, first.
- **Spends**, in full, and the question whether the user agrees to it.
- **Your steps:** the README's order, the exact commands, how long each takes and what each spends.
- **The agent's results so far.**

On an unambiguous yes, to the checks and to the spend: set `Ready`. **Stop.** The user runs their steps when they can. Meanwhile pipeline-design and test-planning can go on; build-planning waits for this probe.

- **Title** states the claim ("Plaid Trial covers my institutions with 12–24 months of history"), so a fail reads as the claim being false.
- **Folder** is `probes/PB-NN-<slug>/`, slug in lower-case kebab.
- **Hash** stays `—` until `dt probes --stamp` writes it. Never type one. It covers every file in the folder except `evidence/`, `out/`, dot-files, `__pycache__/`, `*.pyc` and `*.md`, so an input such as `decommissioned_meters.csv` counts and a README edit doesn't.

- **Last run** is the `run_at` of the `results.json` that Record last read, copied verbatim (`2026-10-21T08:40:02Z`); `dt` compares the two.
- **Informs** lists only IDs that exist (`probe-informs` lint). The contract types are the ones whose fields the evidence could change.
- **Docs read** names the pages behind every claim the entry settles without a check, with the date read.
- **Checks**, one row per unknown, addressable as `PB-01.C3`. Every row has a **Pass** cell. A measure-only check states the threshold it is compared with, taken from the requirement. - **Result** is `—` until a run, then `pass`, `fail` or `pass, note` in a few words ("13–24 months; a4: 3, opened 3 months ago").
- **Verdict** is `pass` when every check passed. A fail names the checks and why, in one line.
- **Size:** about 8 lines plus one line per check.

## Status

`Draft` (spec waiting for approval) → `Ready` (approved, code written, waiting for a run) → `Answered · pass|fail · YYYY-MM-DD`, or `Waived · YYYY-MM-DD — <the user's reason>`.

- A decision that cites a Ready probe stays `Proposed`. build-planning won't plan a milestone the probe reaches until it is Answered or Waived.
- Waiving is only ever the user's call, in their words. The decision's Risks line stays.
- A withdrawn probe collapses to one struck line under `## Retired`: `- ~~PB-04: The weather API serves hourly history from 2015~~ Retired 2026-11-02: AD-04 dropped weather features`. Its folder is deleted after the user agrees, and the ID is never reused. Omit the heading until the first retirement.

## Folder

```
probes/PB-NN-<slug>/
  probe.py          the user's checks; reads keys through load_env()
  public.py         optional: the agent's checks; no os.environ, getenv or .env anywhere in it
  probe_kit.py      copied from templates/, unchanged
  README.md         from templates/README.md: who runs what, in order, and what each step spends
  .env.example      variable names only
  evidence/         committed, written only by the scripts: results.json, schema.json, samples/
  out/              gitignored, 0700: raw responses, tokens, hashed ids, the user's own lists
  .env              gitignored, written by the user
```

- **Small.** Each function answers one check. No retries, config layers, classes or abstractions beyond what a check needs. `dt lint` warns over 400 code lines (`probe-large`).
- **Raw HTTP.** Stdlib `urllib` against the documented endpoints, so the evidence is the payload the adapter will see. When an SDK is unavoidable, declare it in PEP 723 inline metadata and run with `uv run`. `pyproject.toml` never changes.
- **Settings from the environment, real by default:** `os.environ.get("PLAID_BASE_URL", <real host>)`, `PLAID_ENV`. The evals point a probe at a fake vendor this way. `.env` holds keys only (`safety.md`).
- **Use the build's settings** wherever a setting can't be changed later (Plaid's `days_requested`).
- **One entry per check** in the code: a `cN_<what>()` function that ends in `record("CN", …)`. A step is a function calling checks in the README's order, and returns rather than exits. The script ends in `run({"<step>": function, …}, keys=[…])`, which runs `probe.py <step>` and writes evidence once, also when the run fails.
- **Order across probes.** A step that reads another probe's `out/` is named in both READMEs' "Steps, in order", with the step it waits for.

# Runners, secrets and personal data

The agent never sees a secret, and the script redacts, never the agent. Every mode keeps these rules.

## Runners

| Runner | Allowed when | Examples |

Through Bash, never `cat`, `grep`, `head`, `source`, `ls -la` or copy those paths either: the guard can't cover every shell command, so the rule is yours to keep.

## Redaction, in the script

- **Allow-list.** `allow(obj, fields)` keeps only the named fields (dotted paths reach inside). Into `record()` go counts, booleans, dates at month resolution (days only when a check needs them), enum values, field names and types. Never amounts, balances, names, masks, ids, tokens or free text.
- **Free text** only when a check asks for it (merchant descriptions for a normalization rule). The check bounds the count, masks digits, and skips person-to-person and payroll rows by category and pattern. The user reviews every line at the Record gate before it is committed.
- **Ids** are salted hashes kept in `out/`, for checks that ids stay stable across runs. Evidence holds counts of ids, never ids.
- **Samples.** `shape_sample(name, rows, keep=(enum fields…))` keeps field names, types, nulls and the named enum values. Numbers become `1` or `1.0` with the sign kept, strings `"<str:N>"`, id-like fields `"<id>"`, and dates move by whole weeks to 2001, keeping weekday and order. The real rows go to `out/<name>.raw.json`.
- **Floats** in `observed` are rounded (4 places), so no long digit run reaches the scan.
- **Scan, fail closed.** `write_evidence()` scans everything it is about to write for token shapes, secret keys (`sk-…`), credentials in URLs, hex runs of 24 or more, mixed base64 runs of 32 or more, runs of 8 or more digits and card-like groups, emails, phone numbers, and every value in `.env` or passed through `load_env()`. On a hit, nothing reaches `evidence/`: the output goes to `out/evidence.rejected.json`, and the script names the pattern and exits 1. Fix the allow-list, never the pattern. `dt probes --scan` runs the same check on committed evidence (`evidence_leaks`).
- **Licensed data.** Vendor terms usually allow personal local storage and forbid redistribution. Market-data samples keep the shape and a few rows with values replaced, and real values stay in `out/`. Record the terms that were checked in Spends or Caveats.

## Spending

A probe can spend what the build needs. Spends names it, and the user agrees at the New gate before anything runs.

- **Check cheaply before spending.** A free lookup (`/institutions/search`) or a free sample goes first, and its failure stops the run before anything is spent.
- **Use the build's exact settings** where a setting can't be changed later.
- **Keep what was spent.** Items that count against a cap stay in `out/`, and the decision's Consequences say the build adopts them. Tokens move to the service's secret store; they never pass through docs.
- **Money.** Name the amount: a subscription month taken before the decision is Accepted is the user's call.

def load_env(names: list[str]) -> dict[str, str]:

def allow(obj, fields: list[str]):
    """Only the named fields (dotted paths reach into dicts); lists are filtered item by item."""
    if isinstance(obj, list):
        return [allow(o, fields) for o in obj]
    kept: dict = {}
    for path in fields:
        head, _, rest = path.partition(".")
        if not isinstance(obj, dict) or head not in obj:
            continue
        value = obj[head]
        if rest and isinstance(value, (dict, list)):
            value = allow(value, [rest])
            if isinstance(value, dict) and isinstance(kept.get(head), dict):
                value = {**kept[head], **value}
        kept[head] = value
    return kept

def shape_sample(name: str, rows: list, keep: tuple[str, ...] = ()) -> None:
    """Shape-faithful rows for evidence/samples/<name>.json. Field names, types, nulls and the `keep`
    enum fields stay; numbers become 1.00 with the sign kept, strings "<str:N>", ids "<id>", dates move
    by whole weeks to 2001 (weekday and order kept). The real rows go to out/<name>.raw.json."""
    save_private(f"{name}.raw.json", rows)
    firsts = [m for m in (DATE.match(s) for s in _strings(rows)) if m]
    shift = dt.timedelta(0)
    if firsts:
        first = min(dt.date(*map(int, m.groups())) for m in firsts)
        shift = dt.timedelta(weeks=round((dt.date(2001, 1, 1) - first).days / 7))

    def mask(v, key=""):
        if isinstance(v, dict):
            return {k: mask(x, k) for k, x in v.items()}
        if isinstance(v, list):
            return [mask(x, key) for x in v]
        if v is None or isinstance(v, bool) or key in keep:
            return v
        if ID_KEY.search(key):
            return "<id>"
        if isinstance(v, (int, float)):
            return (-1 if v < 0 else 1) * (1 if isinstance(v, int) else 1.0)
        m = DATE.match(v)
        if m:
            return (dt.date(*map(int, m.groups())) + shift).isoformat() + v[10:]
        return f"<str:{len(v)}>"

    _samples[name] = mask(rows)
    observe_schema(name, rows)


def observe_schema(endpoint: str, rows: list) -> None:
    """Every field path seen in `rows`, its types and null count, for evidence/schema.json."""
    seen = _schema.setdefault(endpoint, {})

    def walk(v, path):
        if isinstance(v, dict):
            for k, x in v.items():
                walk(x, f"{path}.{k}" if path else k)
            return
        if isinstance(v, list) and v and isinstance(v[0], dict):
            for x in v:
                walk(x, f"{path}[]")
            return
        entry = seen.setdefault(path or "$", {"types": [], "nulls": 0, "seen": 0})
        entry["seen"] += 1
        if v is None:
            entry["nulls"] += 1
        elif type(v).__name__ not in entry["types"]:
            entry["types"].append(type(v).__name__)

    for row in rows:
        walk(row, "")


def scan(text: str) -> list[str]:

    runs, 8+ digit runs, card numbers, emails, phones, and any .env value. Empty means clean."""

def script_hash(folder: Path = HERE) -> str:
    """First 8 hex of sha256 over the folder's code files, as `dt probes --stamp` computes it: every
    file except top-level evidence/ and out/, dot-files and dot-folders, __pycache__/, *.pyc and *.md."""
    files = []
    for d, subs, names in os.walk(folder):
        rel_d = os.path.relpath(d, folder).replace(os.sep, "/")
        subs[:] = sorted(x for x in subs if not x.startswith(".") and x != "__pycache__"
                         and not (rel_d == "." and x in ("evidence", "out")))
        files += [os.path.normpath(os.path.join(rel_d, n)).replace(os.sep, "/") for n in names
                  if not n.startswith(".") and not n.endswith((".pyc", ".md"))]
    h = hashlib.sha256()
    for rel in sorted(files):
        h.update(rel.encode() + b"\0" + (Path(folder) / rel).read_bytes() + b"\0")
    return h.hexdigest()[:8]

class VendorError(Exception):
    """An HTTP refusal: the status and the vendor's error code, never the request."""

    def __init__(self, status: int, vendor_code: str):
        super().__init__(f"HTTP {status} {vendor_code}")
        self.code = status


def get(url: str) -> tuple[int, str]:
    try:
        with urllib.request.urlopen(url, timeout=120) as r:
            return r.status, r.read().decode()
    except urllib.error.HTTPError as e:
        return e.code, e.read().decode(errors="replace")


def error_code(body: str) -> str:
    try:
        return str(json.loads(body)["quandl_error"]["code"])
    except (ValueError, KeyError, TypeError):
        return ""


def url(table: str, **params) -> str:
    q = {**params, "api_key": os.environ["SHARADAR_API_KEY"], "format": "csv"}
    return f"{BASE}/{table}?{urllib.parse.urlencode(q)}"

    q = {**params, "api_key": os.environ["SHARADAR_API_KEY"], "qopts.per_page": 1}
    return f"{NDL}/{table}.csv?{urllib.parse.urlencode(q)}"
