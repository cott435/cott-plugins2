33	### AD-09: Every batch first runs the method's check world
34	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** system
35	- **Context:** TRAIN-06 needs every learning method to learn a hand-derived best behaviour before it is used in a world. Bugs in RL are silent (brief), and methods change while a world is built.
36	- **Decision:** `train.run_check` trains each team method in a config on its check world: for DQN a 6-state corridor with two exits, left of state 0 (reward 0.8) and right of state 5 (reward 1.0), γ = 0.9, so the best action is left in states 0–1 and right in 2–5 and a learner biased to one action can't pass; for PPO a 1-D point that is rewarded for reaching a target, where the best push is the sign of the offset. It needs ≥ 95% agreement over every check-world state. `train.run_batch` runs the same check steps with the batch's method settings before starting any run and refuses the batch on failure. `rllab check <config>` runs it alone.
37	- **Alternatives:** A recorded pass per method version: saves seconds but goes stale silently when code changes. A test only: passes in CI but not for the settings actually used.
38	- **Consequences:** Each batch spends under a minute on the check. A check-world settings override exists because a world's tuned settings (e.g. buffer size) may be too large for a 6-state world.

# Action encoding of the corridor's Discrete(2) space, as in the contract sample
# (tests/contracts/worlds.CheckWorld/recordings/two_exit_corridor.json): 1 moves right.
LEFT, RIGHT = 0, 1
ENCODING = {"left": LEFT, "right": RIGHT}


def expected() -> dict:
    return json.loads((FIXTURE / "expected.json").read_text())["check-discrete"]


def act(a: int) -> np.ndarray:
    return np.array([a], dtype=np.int64)


def position(world: CheckDiscrete, obs: np.ndarray) -> int:
    states = np.asarray(world.states())
    matches = [i for i, row in enumerate(states) if np.array_equal(row, np.asarray(obs)[0])]
    assert len(matches) == 1, "the observation must be exactly one of states()"
    return matches[0]
