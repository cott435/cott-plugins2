47	    def __init__(self, n_actions: int, params: AgentParams, exploration: Exploration, *, seed: int, explore_enabled: bool = True) -> None: ...
48	    def values(self, obs: np.ndarray) -> np.ndarray: ...
49	    def epsilon(self, step: int) -> float: ...
50	```
51	- **Invariants:** single-agent (batches of 1). One value per (observation, action), keyed on the observation's bytes and starting at 0. Each `learn` moves the value toward `reward + gamma · max next value`, with no bootstrap when `terminated` (AGENT-01). `explore_enabled=False` is the `no_explore` ablation (ABL-03). The checkpoint is NPZ. `values(obs)` takes a `(1, *obs_shape)` observation and returns its `(n_actions,)` float64 values, zeros for an unseen observation, without changing the table. `epsilon(step)` is the exploration rate after `step` `learn` calls: `exploration.start` at 0, falling linearly to `exploration.end` at `exploration.decay_steps` and staying there; `act` with `explore=True` uses `epsilon` of the number of `learn` calls so far. Both are pure.
