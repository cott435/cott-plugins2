25:- **RISK-01** Daily returns are log returns.
26-  - Given closes, when returns are computed, then r_t = ln(close_t / close_t−1), dated t.
27:- **RISK-02** Rolling volatility uses only earlier returns.
28-  - Given a window of w, when the volatility for date t is computed, then it is the sample standard deviation (n − 1) of the w returns before t, never t's own return, and there is no value until w earlier returns exist.
29:- **RISK-03** Volatility is annualized over trading days.
30-  - Given a daily volatility σ, when annualized, then the value is σ·√252.
31:- **RISK-04** Each ticker gets a whole-period summary.
32-  - Given returns, when summarized, then the annualized return is 252 × the mean, the annualized volatility is √252 × the sample standard deviation, the Sharpe ratio is their quotient (0 when the volatility is 0; no risk-free rate), and the last rolling volatility is reported.

## Decisions
### AD-01: Standard library only
**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** system
- **Context:** Inputs are a few small CSV files (brief, Constraints).
- **Decision:** `csv`, `math`, `statistics`, `dataclasses`; no pandas or numpy.
- **Alternatives:** pandas — a heavy dependency for a few hundred rows.
- **Consequences:** Types are frozen dataclasses of tuples; the code is explicit about windows and denominators.

### AD-02: One uv workspace, one test tree
**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** system
- **Context:** Two packages in one repo, built by several agents at once.
- **Decision:** A uv workspace with members `packages/mdata` and `packages/risk` (`risk` depends on `mdata`); tests live under `tests/` by role and package.
- **Alternatives:** pytest's `pythonpath` over both `src/` folders — no lock, but nothing checks what each package declares.
- **Consequences:** `uv run pytest` from the root is the whole test run; each worktree gets its own `.venv`.
