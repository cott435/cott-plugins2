34	### AD-05: Seeds from SeedSequence, disjoint held-out ranges, one process per run
35	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** system
36	- **Context:** WORLD-01, WORLD-02, TRAIN-02 and REPLAY-02 need exact repeats; TRAIN-04 and EVAL-03 need seeds never used in training; TRAIN-05 and QR-02 need runs in parallel, one per core.
37	- **Decision:** A run seed spawns the learner's, exploration and episode-seed generators through `np.random.SeedSequence`. An episode seed spawns the world's and the policies' generators inside `core.play_episode`. Training draws episode seeds from [0, 10⁶); evaluation seeds are the fixed `core.EVAL_SEEDS` and `core.FINAL_SEEDS` ranges (see Data). `train.run_batch` runs each config in its own `spawn` process with `torch.set_num_threads(1)` and `torch.use_deterministic_algorithms(True)`.
38	- **Alternatives:** Global `np.random.seed`/`torch.manual_seed`: order-dependent, breaks once evaluation interleaves with training. Threads: the GIL serialises the Python world loop.
39	- **Consequences:** Identical runs are promised on the same machine only (TRAIN-02). In-training evaluation never touches the training generators, so turning evaluation off for a test leaves training identical.

42	### AD-06: Run folders of JSON, JSON Lines and torch checkpoints
43	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** system
44	- **Context:** LOG-01 and LOG-02 need a record and per-episode logs. LOG-06 needs them readable while the run writes, at most one evaluation point behind. A stopped run keeps its checkpoints and is marked incomplete. A run name that already exists is refused (TRAIN edge cases). REPLAY edge cases need a checkpoint to carry its world spec.
45	- **Decision:** One folder per run (see Data). Logs are append-only JSON Lines, flushed at every evaluation point; `run.json` is rewritten atomically (write, then rename) on each status change. A checkpoint is a `torch.save` dict of spec, method configs and state dicts, loaded with `weights_only=True`.
46	- **Alternatives:** Parquet: fast to read but not appendable while a run is live. SQLite: one file for everything, but concurrent writers from parallel runs need care and the files are no longer readable by eye.
47	- **Consequences:** Charts and evaluation read whole JSONL files; at ~10⁴ episodes per run that is instant. A crashed process leaves `run.json` at `running`; `runlog` reports any `running` run with no live process as incomplete.

import numpy as np

def check_actions(spec: WorldSpec, actions: Array, active: Array) -> None:
    """`ActionError` for the first active agent whose action is outside `spec.action`."""
    actions = np.asarray(actions)
    space = spec.action
    for i, agent in enumerate(spec.agents):
        if not active[i]:
            continue
        a = actions[i]
        if isinstance(space, Box):
            inside = np.shape(a) == (space.dims,) and bool(
                np.all((a >= space.low) & (a <= space.high))
            )
        else:
            inside = np.ndim(a) == 0 and float(a).is_integer() and 0 <= a < space.n
        if not inside:
            raise ActionError(agent, a.tolist())


class ReplayWorld:
    """Serves a recorded episode: `recording` holds spec, reset, steps, draws and result."""

    def __init__(self, fx, recording) -> None:
        self.spec = fx.decode(WorldSpec, recording["spec"])
        self._reset = fx.decode(Step, recording["reset"])
        self._steps = [fx.decode(Step, s["step"]) for s in recording["steps"]]
        self.recorded_actions = [fx.decode(Array, s["actions"]) for s in recording["steps"]]
        self._draws = [fx.decode(DrawState, d) for d in recording["draws"]]
        self._result = fx.decode(EpisodeResult, recording["result"])
        self.seeds: list[int] = []
        self.actions: list[Array] = []
        self._t = -1

    def reset(self, seed: int) -> Step:
        self.seeds.append(seed)
        self._t = 0
        return self._reset

    def step(self, actions: Array) -> Step:
        if self._t < 0:
            raise RuntimeError("step before reset")
        if self._t >= len(self._steps):
            raise RuntimeError("step after the episode ended")
        last = self._reset if self._t == 0 else self._steps[self._t - 1]
        check_actions(self.spec, actions, last.active)
        self.actions.append(np.array(actions, copy=True))
        step = self._steps[self._t]
        self._t += 1
        return step

    def result(self) -> EpisodeResult:
        return self._result

    def draw(self) -> DrawState:
        return self._draws[max(self._t, 0)]

def _decode_scalar(tp: Any, data: Any, where: str) -> Any:
    if tp not in SCALAR_FORMS:
        _fail(where, f"no JSON form for {tp!r}")
    accepts, convert = SCALAR_FORMS[tp]
    if not accepts(data):
        _fail(where, f"{data!r} is not a {getattr(tp, '__name__', tp)}")
    return convert(data)


def _decode_array(data: Any, where: str) -> Any:
    if not isinstance(data, dict) or set(data) != {"dtype", "shape", "data"}:
        _fail(where, "expected an array object {dtype, shape, data}")
    return np.asarray(data["data"], dtype=np.dtype(data["dtype"])).reshape(data["shape"])


def _decode_container(origin: Any, args: tuple[Any, ...], data: Any, where: str) -> Any:
    if origin is np.ndarray:
        return _decode_array(data, where)
    if origin in (Mapping, dict):
        if not isinstance(data, dict):
            _fail(where, "expected an object")
        key, value = args or (str, Any)
        return {decode(key, k, where): decode(value, v, f"{where}.{k}") for k, v in data.items()}
    if not isinstance(data, list):
        _fail(where, "expected a list")
    if origin is list or (len(args) == 2 and args[1] is Ellipsis):
        items = [decode(args[0], v, f"{where}[{i}]") for i, v in enumerate(data)]
        return items if origin is list else tuple(items)
    if len(args) != len(data):
        _fail(where, f"expected {len(args)} items, got {len(data)}")
    pairs = enumerate(zip(args, data, strict=True))
    return tuple(decode(a, v, f"{where}[{i}]") for i, (a, v) in pairs)


def decode(tp: Any, data: Any, where: str = "") -> Any:
    """`data` (a JSON form) as a value of type `tp`, checked strictly; `ValueError` if not."""
    if isinstance(typing.get_origin(tp), typing.TypeAliasType):  # numpy's NDArray[...]
        tp = typing.get_origin(tp).__value__
    if isinstance(tp, typing.TypeAliasType):
        tp = tp.__value__
    origin, args = typing.get_origin(tp) or tp, typing.get_args(tp)
    if tp is Any or tp is object or origin is typing.Literal:
        if origin is typing.Literal and data not in args:
            _fail(where, f"{data!r} is not one of {args}")
        return data
    if origin in (typing.Union, types.UnionType):

    if origin in (Mapping, dict, list, tuple, np.ndarray):
        return _decode_container(origin, args, data, where)
    if isinstance(tp, type) and dataclasses.is_dataclass(tp):

def _check_choice(data: Any, schema: dict[str, Any], root: dict[str, Any], where: str):

def to_json(value: object) -> object:
    """The JSON form of a run folder value."""
    if dataclasses.is_dataclass(value) and not isinstance(value, type):
        fields = {f.name: to_json(getattr(value, f.name)) for f in dataclasses.fields(value)}
        if isinstance(value, Discrete | Box):
            return {"kind": type(value).__name__.lower(), **fields}
        return fields
    if isinstance(value, Mapping):
        return {str(k): to_json(v) for k, v in value.items()}
    if isinstance(value, tuple | list):
        return [to_json(v) for v in value]
    if isinstance(value, Path):
        return str(value)
    if isinstance(value, datetime):
        return value.isoformat()
    if isinstance(value, np.generic):
        return value.item()
    return value


def _line(value: object) -> str:
    return json.dumps(to_json(value)) + "\n"


class RunWriter:
    """Writes `runs/<world>/<variant>/<name>/`; `RunExistsError` if that folder exists."""

    def __init__(self, root: Path, config: RunConfig, spec: WorldSpec) -> None:
        self.path = root / config.world / config.variant / config.name
        if self.path.exists():
            raise RunExistsError(self.path)
        (self.path / "checkpoints").mkdir(parents=True)
        self._record = RunRecord(
            config, spec, datetime.now(UTC), None, "running", None, self.path
        )
        self._episodes = (self.path / "episodes.jsonl").open("a", encoding="utf-8")
        self._evals = (self.path / "evals.jsonl").open("a", encoding="utf-8")
        self._write_record()

    def episode(self, result: EpisodeResult) -> None:
        self._episodes.write(_line(result))

    def eval(self, point: EvalPoint) -> None:
        """Append `point` and flush every log."""
        self._evals.write(_line(point))
        self._episodes.flush()
        self._evals.flush()

    def checkpoint(self, pct: int, step: int, state: Mapping[str, dict[str, object]]) -> Checkpoint:
        config = self._record.config
        ckpt = Checkpoint(
            config.name,
            pct,
            step,
            self._record.spec,
            dict(config.methods),
            dict(state),
            self.path / "checkpoints" / f"ckpt_{pct}.pt",
        )
        saved = cast("dict[str, object]", to_json(dataclasses.replace(ckpt, state={})))
        torch.save({**saved, "state": ckpt.state}, ckpt.path)
        return ckpt

    def close(self, status: str, failure: Failure | None = None) -> RunRecord:
        self._episodes.close()
        self._evals.close()

            self._record,
            ended=datetime.now(UTC),
            status=_status(status),
            failure=failure,
        )

        temporary.replace(self.path / "run.json")

def train_loop(
    world: World, learners: Mapping[str, Learner], config: RunConfig, root: Path
) -> RunRecord:
    """Exactly `budget` world steps, written through `runlog.RunWriter`, with checkpoints at
    every 10% and evaluations on `EVAL_SEEDS` at every 5%."""
    writer = RunWriter(root, config, world.spec)
    eval_world = copy.deepcopy(world)  # evaluation never resets the training episode
    last = writer.checkpoint(0, 0, _state(learners))
    writer.eval(evaluate(eval_world, learners, 0))
    checkpoints = _marks(config.budget, CHECKPOINT_EVERY)
    evals = _marks(config.budget, EVAL_EVERY)
    step = 0
    try:
        for step in _train_steps(world, learners, config, writer):

def _state(learners: Mapping[str, Learner]) -> dict[str, dict[str, object]]:
    return {team: learner.state_dict() for team, learner in learners.items()}


def _train_steps(
    world: World, learners: Mapping[str, Learner], config: RunConfig, writer: RunWriter
) -> Iterator[int]:
    """Play training episodes up to `config.budget` world steps, logging each finished
    episode, and yield the step count after every world step."""
    # Child 0 of the run seed is the learners' (train.setup); 1 explores, 2 draws episodes.
    explore, episodes = (
        np.random.default_rng(child) for child in np.random.SeedSequence(config.seed).spawn(3)[1:]
    )
    step = 0
    while step < config.budget:
        now = world.reset(int(episodes.integers(TRAIN_SEED_LIMIT)))
        while not now.done and step < config.budget:
            now = _world_step(world, learners, now, explore)
            step += 1
            if now.done:
                writer.episode(world.result())
            yield step


def _world_step(
    world: World, learners: Mapping[str, Learner], now: Step, rng: np.random.Generator
) -> Step:
    """One exploring action per agent, one world step, one transition per team."""
    teams = world.spec.teams
    actions = {t.name: np.asarray(learners[t.name].act(now.obs[list(t.agents)], rng)) for t in teams}
    nxt = world.step(_joint(actions, {t.name: t.agents for t in teams}, len(world.spec.agents)))
    for t in teams:
        rows = list(t.agents)
        learners[t.name].observe(
            Transition(
                obs=now.obs[rows],
                actions=actions[t.name],
                rewards=nxt.rewards[rows],
                next_obs=nxt.obs[rows],
                done=nxt.done,
                truncated=nxt.truncated,
                active=now.active[rows],
            )
        )
    return nxt


def _joint(actions: Mapping[str, Array], agents: Mapping[str, tuple[int, ...]], n: int) -> Array:
    """Per-team actions as one row per agent, in agent order."""
    rows = {i: a for team, act in actions.items() for i, a in zip(agents[team], act, strict=True)}
    return np.stack([rows[i] for i in range(n)])
