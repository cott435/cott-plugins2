1	"""Dataset builder for a temporal-fusion-transformer style forecaster.
2	
3	Turns a long panel (one row per ticker and date) into fixed-length training windows. Each window has an
4	encoder part (the lookback) and a decoder part (the forecast horizon), and the inputs are split the way
5	TFT expects them:
6	
7	- static covariates: constant per ticker (sector, listing exchange, ...), categorical, encoded as ints
8	- known covariates: known in advance for every step, including the decoder steps (calendar features)
9	- observed covariates: only known up to the forecast origin (returns, volume, the engineered features)
10	
11	Targets come from a separate frame (see tft_targets.py) joined on (ticker, date).
12	"""
13	from __future__ import annotations
14	
15	from dataclasses import dataclass, field

17	import numpy as np
18	import pandas as pd

21	@dataclass
22	class WindowSpec:
23	    """Shape of one sample: ``lookback`` encoder steps followed by ``horizon`` decoder steps."""
24	    lookback: int = 63
25	    horizon: int = 5
26	    stride: int = 1
27	    static_cols: list[str] = field(default_factory=lambda: ["sector"])
28	    known_cols: list[str] = field(default_factory=lambda: ["dow", "month", "days_to_month_end"])
29	    observed_cols: list[str] = field(default_factory=lambda: ["log_ret", "log_volume", "range_pct"])
30	    target_cols: list[str] = field(default_factory=lambda: ["fwd_ret_1d"])

33	def add_calendar_features(panel: pd.DataFrame) -> pd.DataFrame:
34	    """Known-in-advance covariates derived from the date only."""

52	        p[c] = p[c].astype(str).map(vocab[c]).astype(np.int64)
53	    return p, vocab

56	def normalise_observed(panel: pd.DataFrame, cols: list[str], window: int = 252) -> pd.DataFrame:
57	    """Per-ticker z-score of observed covariates using a trailing window (no future rows)."""
58	    p = panel.sort_values(["ticker", "date"]).copy()
59	    g = p.groupby("ticker")[cols]
60	    mu = g.transform(lambda s: s.rolling(window, min_periods=20).mean())
61	    sd = g.transform(lambda s: s.rolling(window, min_periods=20).std())
62	    p[cols] = ((p[cols] - mu) / sd.replace(0.0, np.nan)).fillna(0.0)
63	    return p

70	        static   (S, n_static)              int64
71	        known    (S, lookback + horizon, n_known)
72	        observed (S, lookback, n_observed)
73	        target   (S, horizon, n_target)
74	        origin   (S,) the forecast-origin date of each sample (last encoder step)

- **Purpose:** Turns a long (ticker, date) panel into fixed-length encoder/decoder windows with static, known and observed inputs, laid out the way a Temporal Fusion Transformer expects, and splits them by forecast-origin date.
- **Key parts:** `WindowSpec` (dataclass: `lookback=63`, `horizon=5`, `stride=1`, `static_cols`, `known_cols`, `observed_cols`, `target_cols`); `add_calendar_features(panel) -> DataFrame`; `encode_static(panel, cols) -> (DataFrame, vocab)`; `normalise_observed(panel, cols, window=252) -> DataFrame`; `build_windows(panel, targets, spec) -> dict[str, ndarray]`; `split_by_origin(arrays, train_end, valid_end) -> dict[str, dict]`.
- **In → Out:** In: a pandas panel with `ticker`, `date`, `sector` and the feature columns, plus a targets frame (from `tft_targets.py`, which is not in this file) keyed on (ticker, date). Out: arrays `static (S,n_static)` int64, `known (S,L+H,n_known)`, `observed (S,L,n_obs)`, `target (S,H,n_tgt)` float32, plus `origin (S,)` and `ticker (S,)`, then split into train, valid and test.
- **Use for:** A pattern for building sequence-model samples. It shows how to split inputs into static, known-in-advance and observed-only groups, how to scale with trailing per-ticker z-scores, and how to split on the forecast-origin date.
- **Caveats:** Uses pandas, while the project uses Polars. `split_by_origin` has no purge or embargo, so train samples just before `train_end` have targets reaching up to H days into the validation period, and stride-1 windows overlap heavily. `build_windows` silently drops some data: rows without a target are lost in the inner merge (which can cut delisted names' last days), and tickers with fewer than L+H rows are skipped. It also treats consecutive rows as consecutive trading days without checking for date gaps. `encode_static` builds its vocabulary from the full sample, a category not seen there breaks the int cast, and it keeps the first sector value per ticker even if the sector changes later. `normalise_observed` fills NaNs and the first 19 warm-up rows with 0 without saying so. `busday_count` ignores US holidays. All defaults are hard-coded (63/5/1, 252, column names). An empty result returns `np.empty((0,))` with the wrong shape. Whether the targets avoid look-ahead depends on how `fwd_ret_1d` is defined in `tft_targets.py`. No instructions addressed to an AI were found in the text.
