### AD-18: A run's length is a step budget; the time limit is a backstop
**Status:** Accepted · **Date:** 2026-10-18 · **Scope:** learners
- **Context:** QR-03 needs a repeated run to give the same curve, but a run stopped at `time_limit_s` takes a different number of steps each time, and curve points spaced by time land on different steps. TC-31 and TC-32 need a run that ends on a fixed step. QR-01 still caps a run at an hour.
- **Decision:** `TrainSettings.total_steps` (environment steps summed over the world copies) sets a run's length. Curve point k is taken at the first batch step reaching k/`curve_points` of the budget, and `CurvePoint.progress` is steps over budget. `time_limit_s` stays as the backstop. A run that reaches it first ends `finished`, keeps the curve so far and says in its message how many steps it reached. The per-world budgets are set from a measured speed so a run fits the hour. Co-evolution snapshots and the SB3 reference use the same budget (AD-13, AD-08).

### AD-20: Each comparison is a paired sign-flip permutation test, Holm-corrected per world
**Status:** Accepted · **Date:** 2026-10-18 · **Scope:** evaluate
- **Context:** The project's `null-hypothesis-testing` skill is a placeholder with no statistic, null or correction, and the user left the choice to us (UR-46: "Same for the placeholder null-hypothesis-testing skill"). Every agent in a comparison plays the same evaluation seeds 0–99 (AD-10), so scores pair up by seed. The scores aren't normal: Snake scores are capped at 97 and fish survival piles up at the episode's last step. TC-22–TC-26 set what the test must do: pass a planted gap, keep false passes near 5%, give "no difference" for identical sets, decide the ratio margins, and never lower a p-value when asks join the family.
- **Decision:** For each ask (a, b, kind, margin), with margin 1.0 for `beats`, the per-seed differences are d = a − margin × b over the shared seeds and the statistic is mean(d). H0: mean(d) ≤ 0; H1: mean(d) > 0. The null distribution is 10,000 random sign flips of d from a fresh `np.random.default_rng(0)` for each ask, so an ask's raw p doesn't depend on the others; p = (1 + number of flipped means ≥ the observed mean) / 10,001. Holm–Bonferroni across every ask in the `compare` call gives `p_corrected`, and the verdict is `pass` when it is below α (0.05), else `fail`. When a and b are equal seed by seed the ask is `no difference`, with statistic 0 and raw p 1, and it still counts in the family. `Comparison.test` reads "paired sign-flip permutation, Holm". NumPy only.
- **Alternatives:** Paired t-test (SciPy) — leans on the mean differences being near normal, which capped and piled-up scores make an argument rather than a given. An unpaired permutation test — throws away the shared seeds and loses power. Bonferroni — family-wise like Holm but never more powerful. Benjamini–Hochberg — controls the false-discovery rate, not the 5% family-wise rate EVAL-03 asks for.
- **Consequences:** SciPy leaves the stack. The same scores give the same Comparison (QR-03). The smallest p is 1/10,001, far below any Holm threshold a world's family reaches. The Monte Carlo error near p = 0.05 is about ±0.002, so a verdict that close to the line could go the other way with a different resample seed; the seed is fixed, so it doesn't vary between runs.
