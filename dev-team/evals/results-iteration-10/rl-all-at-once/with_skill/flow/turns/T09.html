# New: a probe is written

`probes_unwritten` lists a probe a decision cites with no entry yet (`PB-01 (AD-04)`), or the user asks a question about a service ("does the weather API return hourly history back to 2015?"). Use the shape in `entry.md` and the rules in `safety.md`. `../examples.md` shows the whole round for FinTrack's Plaid probe.

## 1. Read what the probe serves

- The decision and its Risks line (`dt section AD-04`), the requirements it rests on, and the contract types whose fields depend on the source. A user's direct question informs the decision being made. With no decision yet, ask which requirement it serves; a probe that informs nothing isn't written.
- The vendor's **official docs**: one page per question (the pricing or plan page, the endpoint reference, the error and rate-limit pages, the sandbox page), never a homepage or a third-party summary. Note each with the date read. A page that refuses a fetch is named under Open questions, not guessed at.

## 2. Sort every claim the decision rests on

| The claim | Goes to |
|---|---|
| The docs settle it | Docs read, cited; no check |
| The docs are silent, vague ("up to 24 months"), or contradict the design | A check |
| It depends on the user's account, plan, institutions or data | A user check |
| The user gave test facts: known cases the source must hold (GridLoad's ten decommissioned meters, which history must still include) | One check covering every listed case, by count ("10 of 10 have readings"). The list goes in the script, or in `out/` when it is private |

A contradiction between the docs and the decision (the weather API's timestamps are UTC, and the decision says local time) goes to the gate summary at once, as a hand-off to architecture-design, before anything runs.

## 3. Write the entry

Draft, with the checks table. Each check's Pass comes from the requirement it informs, with the ID in the cell ("≥ 12 months where the bank keeps it (DATA-01)"). Order the checks so the cheap ones come first and a failure stops the run before anything is spent. Spends names everything a run uses up.

## 4. Write the folder

1. Copy `templates/probe_kit.py` unchanged, and `templates/README.md` and `templates/.env.example`; fill both in, the README's order across probes included (`entry.md`).
2. Write `public.py` for the agent's checks, if any, and `probe.py` for the user's, ending in `run()`. Each check is one function ending in `record()`. Allow-list every field that reaches evidence.
3. Add the `.gitignore` lines from `safety.md` that are missing.
4. `dt probes --stamp PB-NN` writes the Hash.

## 5. Run the agent's checks

`env -i PATH="$PATH" python3 probes/PB-NN-<slug>/public.py`, then fill those rows' Result. A scan hit means the allow-list is wrong: fix the script and run again, without opening `out/`. Never run `probe.py`, not even with a dry-run flag.

## 6. Gate

Besides SKILL.md's gate, show:
- **Settled by the docs:** each claim and its page, in one line each.

- **Your steps:** the README's order, the exact commands, how long each takes and what each spends.
- **The agent's results so far.**

On an unambiguous yes, to the checks and to the spend: set `Ready`. **Stop.** The user runs their steps when they can. Meanwhile pipeline-design and test-planning can go on; build-planning waits for this probe.
# The probe entry and its folder

Every mode writes to this shape. `dt` parses it, so keep the field names and order exactly.

## Index template: `docs/probes.md`

````markdown

**Last updated:** YYYY-MM-DD

### PB-01: <the claim being checked, as a sentence that can be true or false>
**Folder:** `probes/PB-01-<slug>/` · **Hash:** — · **Status:** Draft · **Milestones:** S<n> · **Last run:** —
- **Question:** <what the decision needs to know, in the user's terms>
- **Informs:** <AD-NN, …> · <requirement IDs> · <contract types, `<component>.<Type>`>
- **Docs read (YYYY-MM-DD):** <the official pages, one per question, never a homepage>
- **Spends:** <Items, paid calls, a subscription month, settings fixed for good; "nothing" only after looking>
- **Checks:** table below
- **Verdict:** —
- **Caveats:** <what a builder must not reuse as is: no retries, localhost-only, placeholder samples>

| Check | What | How | Pass | Runner | Result |
|---|---|---|---|---|---|
| C1 | <one unknown> | <endpoint, page or comparison> | <the threshold, from the requirement it informs> | agent | — |

## Retired
````

- **Title** states the claim ("Plaid Trial covers my institutions with 12–24 months of history"), so a fail reads as the claim being false.
- **Folder** is `probes/PB-NN-<slug>/`, slug in lower-case kebab.
- **Hash** stays `—` until `dt probes --stamp` writes it. Never type one. It covers every file in the folder except `evidence/`, `out/`, dot-files, `__pycache__/`, `*.pyc` and `*.md`, so an input such as `decommissioned_meters.csv` counts and a README edit doesn't.
- **Milestones**: the stage or milestone whose plan waits on the probe, as in `docs/references.md`: `S<n>`, `M<n>`, `all` or `—`. `dt` routes the probe's code to that milestone's tasks like an `RF-NN` entry.
- **Last run** is the `run_at` of the `results.json` that Record last read, copied verbatim (`2026-10-21T08:40:02Z`); `dt` compares the two.
- **Informs** lists only IDs that exist (`probe-informs` lint). The contract types are the ones whose fields the evidence could change.
- **Docs read** names the pages behind every claim the entry settles without a check, with the date read.
- **Checks**, one row per unknown, addressable as `PB-01.C3`. Every row has a **Pass** cell. A measure-only check states the threshold it is compared with, taken from the requirement. A check only a person can see has runner `user (manual)`; a check that runs on a sandbox key has `user (sandbox key)`. Runners are defined in `safety.md`.
- **Result** is `—` until a run, then `pass`, `fail` or `pass, note` in a few words ("13–24 months; a4: 3, opened 3 months ago").
- **Verdict** is `pass` when every check passed. A fail names the checks and why, in one line.
- **Size:** about 8 lines plus one line per check.

## Status

`Draft` (spec waiting for approval) → `Ready` (approved, code written, waiting for a run) → `Answered · pass|fail · YYYY-MM-DD`, or `Waived · YYYY-MM-DD — <the user's reason>`.

- A decision that cites a Ready probe stays `Proposed`. build-planning won't plan a milestone the probe reaches until it is Answered or Waived.
- Waiving is only ever the user's call, in their words. The decision's Risks line stays.
- A withdrawn probe collapses to one struck line under `## Retired`: `- ~~PB-04: The weather API serves hourly history from 2015~~ Retired 2026-11-02: AD-04 dropped weather features`. Its folder is deleted after the user agrees, and the ID is never reused. Omit the heading until the first retirement.

## Folder

```
probes/PB-NN-<slug>/
  probe.py          the user's checks; reads keys through load_env()
  public.py         optional: the agent's checks; no os.environ, getenv or .env anywhere in it
  probe_kit.py      copied from templates/, unchanged
  README.md         from templates/README.md: who runs what, in order, and what each step spends
  .env.example      variable names only
  evidence/         committed, written only by the scripts: results.json, schema.json, samples/
  out/              gitignored, 0700: raw responses, tokens, hashed ids, the user's own lists
  .env              gitignored, written by the user
```

- **Small.** Each function answers one check. No retries, config layers, classes or abstractions beyond what a check needs. `dt lint` warns over 400 code lines (`probe-large`).
- **Raw HTTP.** Stdlib `urllib` against the documented endpoints, so the evidence is the payload the adapter will see. When an SDK is unavoidable, declare it in PEP 723 inline metadata and run with `uv run`. `pyproject.toml` never changes.
- **Settings from the environment, real by default:** `os.environ.get("PLAID_BASE_URL", <real host>)`, `PLAID_ENV`. The evals point a probe at a fake vendor this way. `.env` holds keys only (`safety.md`).
- **Use the build's settings** wherever a setting can't be changed later (Plaid's `days_requested`).
- **One entry per check** in the code: a `cN_<what>()` function that ends in `record("CN", …)`. A step is a function calling checks in the README's order, and returns rather than exits. The script ends in `run({"<step>": function, …}, keys=[…])`, which runs `probe.py <step>` and writes evidence once, also when the run fails.
- **Order across probes.** A step that reads another probe's `out/` is named in both READMEs' "Steps, in order", with the step it waits for.
- Errors print the HTTP status and the vendor's error code, never headers, URLs with keys in them, or bodies.

## Evidence

`evidence/results.json`, written by `write_evidence()`, is the only file Record reads:

```json
{"probe": "PB-01", "script_hash": "5c1e09ab", "run_at": "2026-10-20T18:02:11Z",
 "runner": "user", "env": "production", "base_url": "https://production.plaid.com",
 "checks": {"C2": {"pass": true, "observed": {"listed": 6, "found": 6}, "note": "brokerage: investments only"}}}
```

`pass` is `true`, `false`, or `null` for a measured check the script leaves to Record to judge against the Pass cell. A failed run adds `error`: `{"kind": "usage", "steps": […]}` for a missing or unknown step, `missing` with the key names, or `exception` with the step, the class, an HTTP status or file name when there is one, and `frame`: the file, line and function in the probe's own code where it failed. A re-run of the same code keeps the checks it didn't record again, so a second-day run adds C6 and C7 to the first day's. A run of changed code replaces them all. `samples/<name>.json` holds shape-faithful rows from `shape_sample()`. `schema.json` lists each field path seen, with its types and null count. # Runners, secrets and personal data

The agent never sees a secret, and the script redacts, never the agent. Every mode keeps these rules.

## Runners

| Runner | Allowed when | Examples |
|---|---|---|
| **agent** | The check reads no credential, or only one the vendor publishes for everyone, and touches nothing of the user's | Public docs and pricing pages (WebFetch); keyless endpoints; a weather API's published `demo` key on its sample city |

## Keys

- Scripts read keys through `load_env()`: the environment, else the probe's `.env`. `.env` holds keys only, because every value in it is treated as a secret. Settings (`PLAID_ENV`, a base URL) are read with `os.environ.get(name, default)` and set in the shell. Never from command-line arguments, which end up in shell history. Never printed, logged or echoed in an error.
- The user writes `.env` from `.env.example`. Neither the skill nor the README asks them to paste a key into chat. If they paste one anyway, say it should be rotated, and don't repeat it.

Through Bash, never `cat`, `grep`, `head`, `source`, `ls -la` or copy those paths either: the guard can't cover every shell command, so the rule is yours to keep.

## Redaction, in the script

- **Allow-list.** `allow(obj, fields)` keeps only the named fields (dotted paths reach inside). Into `record()` go counts, booleans, dates at month resolution (days only when a check needs them), enum values, field names and types. Never amounts, balances, names, masks, ids, tokens or free text.
- **Free text** only when a check asks for it (merchant descriptions for a normalization rule). The check bounds the count, masks digits, and skips person-to-person and payroll rows by category and pattern. The user reviews every line at the Record gate before it is committed.
- **Ids** are salted hashes kept in `out/`, for checks that ids stay stable across runs. Evidence holds counts of ids, never ids.
- **Samples.** `shape_sample(name, rows, keep=(enum fields…))` keeps field names, types, nulls and the named enum values. Numbers become `1` or `1.0` with the sign kept, strings `"<str:N>"`, id-like fields `"<id>"`, and dates move by whole weeks to 2001, keeping weekday and order. The real rows go to `out/<name>.raw.json`.
- **Floats** in `observed` are rounded (4 places), so no long digit run reaches the scan.
- **Scan, fail closed.** `write_evidence()` scans everything it is about to write for token shapes, secret keys (`sk-…`), credentials in URLs, hex runs of 24 or more, mixed base64 runs of 32 or more, runs of 8 or more digits and card-like groups, emails, phone numbers, and every value in `.env` or passed through `load_env()`. On a hit, nothing reaches `evidence/`: the output goes to `out/evidence.rejected.json`, and the script names the pattern and exits 1. Fix the allow-list, never the pattern. `dt probes --scan` runs the same check on committed evidence (`evidence_leaks`).
- **Licensed data.** Vendor terms usually allow personal local storage and forbid redistribution. Market-data samples keep the shape and a few rows with values replaced, and real values stay in `out/`. Record the terms that were checked in Spends or Caveats.

## Spending

A probe can spend what the build needs. Spends names it, and the user agrees at the New gate before anything runs.

- **Check cheaply before spending.** A free lookup (`/institutions/search`) or a free sample goes first, and its failure stops the run before anything is spent.

- **Keep what was spent.** Items that count against a cap stay in `out/`, and the decision's Consequences say the build adopts them. Tokens move to the service's secret store; they never pass through docs.
- **Money.** Name the amount: a subscription month taken before the decision is Accepted is the user's call.

AD-04's shared-episode VecEnv, for PB-01 only. The build's worlds.make_tank and reference adapter
replace all of it. NumPy at import; gymnasium, stable-baselines3 and torch only inside functions.

    python tank.py child <seed> <agent_steps>    # one seeded training run, for C3: JSON on stdout

from __future__ import annotations

import json
import sys
import time

import numpy as np

N_FISH, R, SIGHT, BALL_SPEED, TOP, MAX_TURN, DT, STEPS, K = 8, 1.0, 0.25, 0.5, 0.4, 0.5, 0.1, 600, 3
BALL_R = 0.05  # touch distance; TankSettings doesn't name one
OBS_DIM = 2 + 4 + 4 + 4 * K + 1  # heading, ball, wall, K nearest fish (seen, dx, dy, dist each), alive
EVAL_SEEDS = range(10_000, 10_200)  # 200 unseen tanks (EVAL-03, EVAL-04)


def _in_disc(rng, r):
    a, d = rng.uniform(0, 2 * np.pi), r * np.sqrt(rng.uniform())
    return np.array([d * np.cos(a), d * np.sin(a)])


def _seen(rel, ok):
    """(n, 2) offsets -> (n, 4): seen flag, dx, dy, distance; all zero when out of sight (TANK-05)."""
    d = np.linalg.norm(rel, axis=1)
    s = ok & (d <= SIGHT)
    return np.where(s[:, None], np.column_stack([np.ones_like(d), rel, d]), 0.0)


class Tank:
    def reset(self, rng):
        self.ball = _in_disc(rng, R - BALL_R)
        a = rng.uniform(0, 2 * np.pi)
        self.vel = BALL_SPEED * np.array([np.cos(a), np.sin(a)])
        fish = []
        while len(fish) < N_FISH:  # TANK-03: a quarter-radius from the ball
            p = _in_disc(rng, R)
            if np.linalg.norm(p - self.ball) >= SIGHT * R:
                fish.append(p)
        self.pos, self.head = np.array(fish), rng.uniform(0, 2 * np.pi, N_FISH)
        self.alive, self.survived, self.t = np.ones(N_FISH, bool), np.zeros(N_FISH), 0
        return self.obs()

    def step(self, action):
        """action (N_FISH, 2) in [-1, 1]: turn, speed. Returns (caught, over)."""
        a, live = np.clip(action, -1, 1), self.alive.copy()
        self.head[live] += a[live, 0] * MAX_TURN
        move = np.column_stack([np.cos(self.head), np.sin(self.head)]) * ((a[:, 1] + 1) / 2 * TOP * DT)[:, None]
        p = self.pos[live] + move[live]
        r = np.linalg.norm(p, axis=1, keepdims=True)
        self.pos[live] = np.where(r > R, p / np.maximum(r, 1e-12) * R, p)  # TANK-01
        self.ball += self.vel * DT
        d = np.linalg.norm(self.ball)
        if d > R - BALL_R:  # TANK-02: mirror off the wall, speed unchanged
            n = self.ball / d
            self.ball = n * (2 * (R - BALL_R) - d)
            self.vel -= 2 * (self.vel @ n) * n
        self.t += 1
        self.survived[live] = self.t * DT
        caught = live & (np.linalg.norm(self.pos - self.ball, axis=1) < BALL_R)  # TANK-06
        self.alive &= ~caught
        return caught, not self.alive.any() or self.t >= STEPS  # TANK-07

    def obs(self, live=None):
        live = self.alive if live is None else live
        o = np.zeros((N_FISH, OBS_DIM), np.float32)
        o[:, 0], o[:, 1] = np.cos(self.head), np.sin(self.head)
        o[:, 2:6] = _seen(self.ball - self.pos, np.ones(N_FISH, bool))
        r = np.linalg.norm(self.pos, axis=1)
        o[:, 6:10] = _seen(self.pos / np.maximum(r, 1e-12)[:, None] * (R - r)[:, None], np.ones(N_FISH, bool))
        rel = self.pos[None] - self.pos[:, None]
        dist = np.linalg.norm(rel, axis=2)
        dist[~(live[None] & live[:, None]) | np.eye(N_FISH, dtype=bool)] = np.inf
        order, rows = np.argsort(dist, axis=1)[:, :K], np.arange(N_FISH)
        for k in range(K):
            j = order[:, k]
            o[:, 10 + 4 * k:14 + 4 * k] = _seen(rel[rows, j], np.isfinite(dist[rows, j]))
        o[:, -1] = 1
        o[~live] = 0
        return o


def swim_away(tank, o):
    """TANK-11: flee a visible ball at top speed, else keep heading, sliding along the wall."""
    want = tank.head.copy()
    sees = o[:, 2] > 0
    want[sees] = np.arctan2(-o[sees, 4], -o[sees, 3])
    r = np.linalg.norm(tank.pos, axis=1)
    out = tank.pos / np.maximum(r, 1e-12)[:, None]
    h = np.column_stack([np.cos(tank.head), np.sin(tank.head)])
    wall = ~sees & (r >= R - 1e-9) & ((h * out).sum(1) > 0)
    tang = np.column_stack([-out[:, 1], out[:, 0]]) * np.sign((h * np.column_stack([-out[:, 1], out[:, 0]])).sum(1) + 1e-12)[:, None]
    want[wall] = np.arctan2(tang[wall, 1], tang[wall, 0])
    turn = (want - tank.head + np.pi) % (2 * np.pi) - np.pi
    return np.column_stack([np.clip(turn / MAX_TURN, -1, 1), np.ones(N_FISH)])


def play(policy, seeds=EVAL_SEEDS):
    """Mean survival time (TANK-08) of each seeded tank under policy(tank, obs) -> actions."""
    tank, scores = Tank(), []
    for s in seeds:
        o, over = tank.reset(np.random.default_rng(s)), False
        while not over:
            _, over = tank.step(policy(tank, o))
            o = tank.obs()
        scores.append(float(tank.survived.mean()))
    return scores


def make_vec_env():
    """AD-04: one slot per fish in one tank. A caught slot is done once, with its terminal observation,
    then returns a zero observation (alive flag 0) and zero reward until the tank episode ends; then every
    slot resets together. Survivors at 60 s are done with TimeLimit.truncated."""
    from gymnasium import spaces
    from stable_baselines3.common.vec_env import VecEnv

    class SharedTank(VecEnv):
        def __init__(self):
            super().__init__(N_FISH, spaces.Box(-np.inf, np.inf, (OBS_DIM,), np.float32),
                             spaces.Box(-1.0, 1.0, (2,), np.float32))
            self.tank, self.rng, self._seed = Tank(), np.random.default_rng(), None
            self.scores, self.slot_done_ok, self.dead_violations, self.truncations = [], [], 0, 0

        def seed(self, seed=None):
            self._seed = seed
            return [seed] * N_FISH

        def reset(self):
            if self._seed is not None:
                self.rng, self._seed = np.random.default_rng(self._seed), None
            self.n_done = np.zeros(N_FISH, int)
            return self.tank.reset(self.rng)

        def step_async(self, actions):
            self._actions = actions

        def step_wait(self):
            was = self.tank.alive.copy()
            caught, over = self.tank.step(self._actions)
            term = self.tank.obs(live=was)
            obs = self.tank.obs()
            rew = np.where(self.tank.alive, DT, 0.0).astype(np.float32)
            done = caught | (over & self.tank.alive)
            infos = [{} for _ in range(N_FISH)]
            for i in np.flatnonzero(done):
                infos[i]["terminal_observation"] = term[i]
                if self.tank.alive[i]:
                    infos[i]["TimeLimit.truncated"] = True
                    self.truncations += 1
            dead = ~was
            self.dead_violations += int(np.any(obs[dead] != 0) or np.any(rew[dead] != 0) or np.any(done[dead]))
            self.n_done += done
            if over:
                self.scores.append(float(self.tank.survived.mean()))
                self.slot_done_ok.append(bool(np.all(self.n_done == 1)))
                obs = self.reset()
            return obs, rew, done, infos

        def close(self):
            pass

        def get_attr(self, name, indices=None):
            return [getattr(self, name, None)] * len(self._get_indices(indices))

        def set_attr(self, name, value, indices=None):
            setattr(self, name, value)

        def env_method(self, name, *args, indices=None, **kwargs):
            return [None] * len(self._get_indices(indices))

        def env_is_wrapped(self, wrapper_class, indices=None):
            return [False] * len(self._get_indices(indices))

    return SharedTank()


def train(seed, agent_steps=None, minutes=None):
    """SB3 PPO with ppo.PPOSettings' defaults mapped by meaning: n_steps counts agent-steps across the
    8 slots in PPOSettings and per slot in SB3, so 2048 // 8. One torch thread, CPU only."""
    import torch
    from stable_baselines3 import PPO
    from stable_baselines3.common.callbacks import BaseCallback

    torch.set_num_threads(1)
    env = make_vec_env()
    model = PPO("MlpPolicy", env, learning_rate=3e-4, n_steps=2048 // N_FISH, batch_size=64, n_epochs=10,
                gamma=0.99, gae_lambda=0.95, clip_range=0.2, ent_coef=0.0, vf_coef=0.5, max_grad_norm=0.5,
                policy_kwargs={"net_arch": {"pi": [64, 64], "vf": [64, 64]}, "log_std_init": 0.0},
                seed=seed, device="cpu")
    end = time.monotonic() + (minutes or 0) * 60

    class Clock(BaseCallback):
        def _on_step(self):
            return minutes is None or time.monotonic() < end

    start = time.monotonic()
    model.learn(total_timesteps=agent_steps or 10**12, callback=Clock())
    return model, env, time.monotonic() - start

    uv run probes/PB-01-sb3-ppo-tank/public.py smoke       # C2, C3

import json
import subprocess
import sys
from importlib.metadata import version
from pathlib import Path

import numpy as np

from probe_kit import record, run
import tank

REPRO_STEPS = 49_152  # 24 rollouts of 2,048 agent-steps, about 10 tank episodes


def c1_baseline():
    t, rng, ok = tank.Tank(), np.random.default_rng(0), {"start_clear": True, "inside": True, "ball_speed": True}
    for s in range(50):  # the stand-in obeys TANK-01-TANK-03 under random fish
        t.reset(np.random.default_rng(s))
        ok["start_clear"] &= bool(np.all(np.linalg.norm(t.pos - t.ball, axis=1) >= tank.SIGHT))
        over = False
        while not over:
            _, over = t.step(rng.uniform(-1, 1, (tank.N_FISH, 2)))
            ok["inside"] &= bool(np.all(np.linalg.norm(t.pos, axis=1) <= tank.R + 1e-9))
            ok["ball_speed"] &= bool(abs(np.linalg.norm(t.vel) - tank.BALL_SPEED) < 1e-9)
    away = tank.play(tank.swim_away)
    rand = tank.play(lambda t, o: rng.uniform(-1, 1, (tank.N_FISH, 2)))
    m = float(np.mean(away))
    record("C1", {"swim_away_mean_s": round(m, 2), "random_mean_s": round(float(np.mean(rand)), 2),
                  "games": len(away), "ceiling_for_1_5x_s": round(60 / 1.5, 2), **ok},
           m <= 40.0 and all(ok.values()))


def c2_smoke():
    model, env, secs = tank.train(seed=0, agent_steps=12_288)
    steps = model.num_timesteps
    record("C2", {"updates": int(model._n_updates), "tank_episodes": len(env.scores),
                  "every_slot_done_once": all(env.slot_done_ok), "dead_slot_violations": env.dead_violations,
                  "truncated_survivors": env.truncations, "agent_steps_per_s": round(steps / secs, 1),
                  "projected_agent_steps_60min": int(steps / secs * 3600) // 1000 * 1000,
                  "versions": {p: version(p) for p in ("stable-baselines3", "gymnasium", "torch", "numpy")},
                  "python": sys.version.split()[0]},
           model._n_updates > 0 and len(env.scores) > 0 and all(env.slot_done_ok) and env.dead_violations == 0)


def c3_repro():
    def child(seed):
        out = subprocess.run([sys.executable, str(Path(tank.__file__)), "child", str(seed), str(REPRO_STEPS)],
                             capture_output=True, text=True, check=True)
        return json.loads(out.stdout.strip().splitlines()[-1])

    a, b, c = child(0), child(0), child(1)
    same = a["scores"] == b["scores"] and a["params"] == b["params"]
    record("C3", {"episodes": len(a["scores"]), "curves_equal": a["scores"] == b["scores"],
                  "weights_equal": a["params"] == b["params"], "other_seed_differs": a["scores"] != c["scores"],
                  "fresh_processes": 3, "agent_steps_each": REPRO_STEPS},
           same and a["scores"] != c["scores"] and len(a["scores"]) > 0)


def smoke():
    c2_smoke()
    c3_repro()


run({"baseline": c1_baseline, "smoke": smoke}, runner="agent")

MINUTES = float(os.environ.get("PB01_MINUTES", "60"))  # QR-01; a setting, not a key


def c4_learn():
    model, env, secs = tank.train(seed=0, minutes=MINUTES)
    model.save(private("sb3_ppo_tank.zip"))
    trained = tank.play(lambda t, o: model.predict(o, deterministic=True)[0])
    away = tank.play(tank.swim_away)
    curve = env.scores
    picks = np.linspace(0, len(curve) - 1, min(20, len(curve))).round().astype(int) if curve else []

           ratio >= 1.5 and secs <= MINUTES * 60 + 60)
