## What it catches

```python
# yourpackage/core/engine.py

```
```text
Layers: cli > services > core
```

## Generating contracts from the architecture

Contracts are generated, never hand-written (CONSTRAINTS.md Boundaries says "do not edit"):
- **Source:** single package: each component's `Depends on` column. Multi-package: the package dependency rules. Contracts sit between component subfolders (`pkg.data`) in a single package and between packages in multi.
- **Shape:** order the components so every dependency points down, then write one `layers` contract, top first. Components that don't depend on each other share a layer: `"pkg.a | pkg.b"` (independent siblings).
- **Narrower rules:** if a component may import only some of the layers below it (`reserve` → `profile`, never `data`), add a `forbidden` contract for that pair.
- **Not built yet:** wrap a module that doesn't exist in parentheses, `"(pkg.report)"`. The layer is optional while missing and enforced once it exists (verified). Without that, a fresh skeleton fails with `Missing layer`. `dt status` flags parentheses around a module that now exists; Extend removes them.
- **Grow:** when a component becomes a package, Extend rewrites its component contract as a package contract. The rule is the same, so code that passed keeps passing.

```toml
[[tool.importlinter.contracts]]
name = "Layers: report > profile > data"
type = "layers"
layers = ["(gridload.report)", "gridload.profile", "gridload.data"]
```

## DTZ: naive datetimes (very relevant for meter data)

```python
ts = datetime.now()                       # DTZ005 -> datetime.now(tz=UTC)
```

```python
datetime.strptime(s, "%Y-%m-%d %H:%M")    # DTZ007
```

## NPY: NumPy

**NPY002 legacy global RNG**
```python
np.random.seed(0)
x = np.random.rand(10)   # NPY002 -> rng = np.random.default_rng(0)
```

Why: global state makes forecasts and simulations hard to reproduce, especially with parallel work.

```python
np.float_(1.0)           # NPY201 -> np.float64
```

Why: these raise `AttributeError` on NumPy 2.

# `git update-ref refs/checks/base HEAD`. Without it, HEAD, which misses changes already committed.
base_commit() {
  git rev-parse -q --verify refs/checks/base 2>/dev/null || git rev-parse -q --verify HEAD 2>/dev/null
}

# A boundary contract is frozen once its folder exists at the base (CR-09): each folder under
# tests/contracts/ at the base, and any file directly in it. A folder new since the base is the
# interface task freezing it, so that task may write it; the next task's base freezes it.
CONTRACTS_GLOB="tests/contracts/**"
frozen_contracts() {
  local base meta path
  base=$(base_commit) || return 0
  git ls-tree "$base" -- tests/contracts/ 2>/dev/null | while IFS=$'\t' read -r meta path; do
    case "$meta" in
      *" tree "*) echo "$path/**" ;;
      *) echo "$path" ;;
    esac
  done
}

protected_globs() {

# Fail if anything matching the given pathspecs changed since the base, untracked files included.
unchanged_since_base() {
  local label="$1" base new
  shift
  echo "-> $label unchanged since $(git rev-parse -q --verify refs/checks/base >/dev/null 2>&1 && echo refs/checks/base || echo HEAD)" >&2
  if ! base=$(base_commit); then
    echo "no commit to compare against: commit the tester's work first" >&2
    rc=1; failed+=("$label: no commit"); return
  fi
  git --no-pager diff --exit-code --stat "$base" -- "$@" >&2 || { rc=1; failed+=("$label changed"); }
  new=$(git ls-files --others --exclude-standard -- "$@")
  if [ -n "$new" ]; then
    printf 'new untracked files in %s:\n%s\n' "$label" "$new" >&2
    rc=1; failed+=("$label changed")
  fi
}

def _layer_names(entry: str) -> tuple[list[str], bool, bool]:
    """A layers entry → (module names, optional, independent siblings). `"(quant.portfolio)"`,
    `"quant.a | quant.b"` (independent), `"quant.a : quant.b"` (siblings that may import each other)."""
    optional = entry.strip().startswith("(")

    return names, optional, "|" in entry

def forbidden_imports(contracts: list[dict]) -> set[tuple[str, str]]:
    """(importer, imported) pairs the contracts forbid, by last module segment."""
    out: set[tuple[str, str]] = set()
    for c in contracts:
        kind = c.get("type", "")
        if kind == "layers":
            layers = [_layer_names(str(e)) for e in c.get("layers", [])]
            for i, (upper, _, independent) in enumerate(layers):
                if independent:
                    out |= {(_short(a), _short(b)) for a in upper for b in upper if a != b}
                for lower, _, _ in layers[i + 1:]:
                    out |= {(_short(b), _short(a)) for a in upper for b in lower}

            out |= {(_short(a), _short(b)) for a in c.get("source_modules", []) for b in c.get("forbidden_modules", [])}

            mods = c.get("modules", [])
            out |= {(_short(a), _short(b)) for a in mods for b in mods if a != b}
    return out


def contract_mismatches(data: dict | None, graph: dict[str, list[str]]) -> list[str] | None:
    """Import-linter contracts vs the architecture's dependency rules (each node may import what it depends
    on, directly or not, and nothing else first-party)."""

        return []
