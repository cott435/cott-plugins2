AGENT-01–AGENT-05 fix the algorithm: a learned value per move, ε-greedy decaying 1.0 → 0.01 over the first half of the games, 100,000 remembered steps, discount 0.9, and a frozen copy refreshed every 1,000 steps.
- **Decision:** `agent.DQNAgent` is written by hand: the replay memory (a NumPy ring buffer), the ε schedule, the target computation, the frozen-copy refresh, the Huber-loss update and the ablation switches. Only the value network uses PyTorch: an MLP of 11 → 256 → 3 built from `torch.nn.Linear`, trained by autograd and `torch.optim.Adam` (lr 1e-3, batch 64). ### AD-03: CPU only; one thread per run, separate processes for the study
**Status:** Accepted · **Date:** 2026-10-18 · **Scope:** system

The pipelines in plain words, for a person reading the plan: per pipeline, its **Purpose** line (or, without one, the requirements it serves), how it runs (trigger; the system pipeline it is a segment of), then each step in order with what it does (its Spine version), what it takes and gives, and the requirements it serves, quoted from the spec.
