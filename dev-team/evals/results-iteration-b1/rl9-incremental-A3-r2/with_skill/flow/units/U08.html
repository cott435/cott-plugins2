46	- **Invariants:** single-agent (batches of 1). One value per (observation, action), keyed on the observation's bytes and starting at 0. 52	```python
53	class Agent(Protocol):
54	    def act(self, obs: np.ndarray, *, explore: bool) -> np.ndarray: ...

56	    def save(self, path: Path) -> None: ...

59	- **Invariants:** one agent acts for one team: `act` takes that team's `(n_agents, *obs_shape)` and returns one action per agent, shaped by the team's `ActionSpace`. `explore=False` never samples or takes a random action (AGENT-07): value learners take the best-valued action and policy learners the policy's mean.
