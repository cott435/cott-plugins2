3	Written while working through the "remove the market, then look at what's left" exercise. Takes a T x N

5	correlation structure and regresses them out, leaving residual (idiosyncratic) returns.
6	
7	The decomposition is fit on the whole panel passed in: the eigenvectors, the standardisation and the
8	loadings all use every row, including the last one.
9	"""

16	def demean_returns(returns: pd.DataFrame, min_obs: int = 60) -> pd.DataFrame:
17	    """Drop thin columns, fill the remaining gaps with 0 and subtract each column's mean.
18	
19	    Columns with fewer than ``min_obs`` non-missing rows are dropped. Missing values left after that are
20	    treated as a zero return (no trade that day).
21	    """
22	    keep = returns.columns[returns.notna().sum() >= min_obs]

24	    return r - r.mean(axis=0)

28	    """Scale each column to unit variance; returns the scaled panel and the per-column std used."""
29	    sd = returns.std(axis=0, ddof=1).replace(0.0, np.nan)
30	    return returns.divide(sd, axis=1).fillna(0.0), sd

33	def pca_factors(returns: pd.DataFrame, k: int = 1) -> tuple[pd.DataFrame, pd.DataFrame, np.ndarray]:
34	    """Top-k principal components of the standardised returns.
35	
36	    Returns:
37	        factors: T x k factor return series (projections of each day onto the eigenvectors).
38	        loadings: N x k eigenvectors, sign-fixed so each column has a positive sum (the market mode then
39	            loads positively on almost every stock).
40	        explained: the fraction of total variance explained by each of the k components.
41	    """
42	    z, _ = standardise(demean_returns(returns))
43	    corr = np.corrcoef(z.to_numpy(), rowvar=False)
44	    evals, evecs = np.linalg.eigh(corr)
45	    order = np.argsort(evals)[::-1]
46	    evals, evecs = evals[order], evecs[:, order]
47	    vecs = evecs[:, :k]
48	    vecs = vecs * np.sign(vecs.sum(axis=0, keepdims=True))
49	    cols = [f"pc{i + 1}" for i in range(k)]
50	    loadings = pd.DataFrame(vecs, index=z.columns, columns=cols)
51	    factors = pd.DataFrame(z.to_numpy() @ vecs, index=z.index, columns=cols)
52	    explained = evals[:k] / evals.sum()
53	    return factors, loadings, explained

56	def residualize(returns: pd.DataFrame, factors: pd.DataFrame) -> tuple[pd.DataFrame, pd.DataFrame]:
57	    """Regress each column of ``returns`` on ``factors`` (OLS with intercept) and return the residuals.
58	
59	    Returns:
60	        residuals: T x N residual returns, same index and columns as the demeaned input.
61	        betas: N x k factor exposures.

- **Purpose:** Removes the market mode (top-k principal components) from a T x N daily returns panel, leaving residual (idiosyncratic) returns.
- **Key parts:** `demean_returns(returns, min_obs=60)`, `standardise(returns) -> (z, sd)`, `pca_factors(returns, k=1) -> (factors, loadings, explained)`, `residualize(returns, factors) -> (residuals, betas)`, `remove_market(returns, k=1) -> dict`, `residual_correlation_check(residuals) -> float`.
- **In → Out:** In: a `pd.DataFrame` of simple daily returns, T dates x N tickers. Out: a dict with residuals (T x N), loadings (N x k), betas (N x k), factors (T x k) and explained (array of length k); `residual_correlation_check` gives the mean absolute off-diagonal correlation as a float.
- **Use for:** The PCA / market-removal step of the proposed return-structure stage, and a sanity test that residual correlation drops sharply compared with raw returns (the `__main__` block runs this on a synthetic one-factor panel).
- **Caveats:**
  - **Look-ahead:** eigenvectors, standardisation, means and betas are all fit on the whole panel, including the last row (the docstring says so). They must be refit on past data only, in rolling or expanding windows, before any out-of-sample use.
  - **Survivorship:** names with fewer than 60 observations are silently dropped.
  - **Zero-filled gaps:** remaining gaps become a 0 return, which pulls correlations toward zero and distorts names that list or delist mid-sample.
  - **Constant columns:** a zero-variance column is filled with 0s, and `np.corrcoef` then returns NaN for it, so `eigh` is likely to fail.
  - **Inconsistent scales:** factors come from standardised returns but are regressed against raw demeaned returns, so betas mix the two scales.
  - **No denoising:** no Marchenko–Pastur step and no error handling. The defaults `k=1` and `min_obs=60` are hard-coded.
