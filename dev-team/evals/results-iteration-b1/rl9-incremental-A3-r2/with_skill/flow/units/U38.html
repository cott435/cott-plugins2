89	### AD-03: Own environment protocol, shaped like Gymnasium
90	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** `core`
91	- **Context:** CORE-01 needs one interface for every environment. REF-01 needs the library agent to train on the same Snake. AGENT-06 keeps library code out of the lab's agents.
92	- **Decision:** `core.Env` is a small Protocol whose `reset(seed)` returns `(obs, info)` and whose `step(actions)` returns a `StepResult` with Gymnasium's fields (observation, reward, terminated, truncated, info), plus `frame()` for replay. 94	- **Consequences:** Truncation (starvation or the step cap) and termination (a collision or a catch) stay separate, so learning targets bootstrap correctly on truncation. The adapter is checked with Stable-Baselines3's `check_env`.

97	### AD-04: Stable-Baselines3 DQN as the reference implementation
98	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** `reference`
99	- **Context:** For Snake, REF-01–REF-03 need an established implementation trained with the same view, rewards, step budget and seeds as the compact-view neural agent; AD-10 covers the tank. The Stable-Baselines3 DQN docs (https://stable-baselines3.readthedocs.io/en/master/modules/dqn.html, read 2026-10-17) say it supports Discrete actions and Box observations, has `buffer_size`, `target_update_interval`, `exploration_fraction`, `seed` and `device`, and offers `MlpPolicy` for vector observations. The custom-environment guide (https://stable-baselines3.readthedocs.io/en/master/guide/custom_env.html, read 2026-10-17) requires a `gymnasium.Env` with `reset(seed, options) → (obs, info)` and a five-field `step`, checked by `check_env`.
100	- **Decision:** `reference` trains Stable-Baselines3 DQN with `MlpPolicy` on the compact view through the AD-03 adapter, with `device="cpu"`. Its hidden layers, learning rate, discount, batch size, memory size, target interval and exploration schedule are mapped one-to-one from the same `RunSettings` the hand-written agent uses. Its curve points come from `evaluate`, exactly as the lab's own agents' do.
101	- **Alternatives:** CleanRL's single-file DQN — very readable, but a script to copy rather than a library to call, so "matching" it blurs into copying it. RLlib — far heavier than one laptop needs.
102	- **Consequences:** Stable-Baselines3 measures exploration as a fraction of training rather than in decay steps, and updates every `train_freq` steps. The mapping fixes `train_freq=1` and `gradient_steps=1`, and sets `exploration_fraction = decay_steps / steps`. Stable-Baselines3 and Gymnasium are an optional install extra, so the rest of the lab never carries them.
103	- **Probe:** none — the two pages above settle the spaces, parameters and environment interface. No account or plan is involved.

def eval_seeds(train_seed: int, n: int) -> list[int]:
    """`1_000_000 + 1000 * train_seed + i` for `i < n`: never a training seed."""
    if not 0 <= n <= SEEDS_PER_TRAIN_SEED:
        raise ValueError(f"n must be within 0..{SEEDS_PER_TRAIN_SEED}, got {n}")
    if not 0 <= train_seed < HELD_OUT_FLOOR:
        raise ValueError(f"train seed must be within 0..{HELD_OUT_FLOOR - 1}, got {train_seed}")
    first = HELD_OUT_FLOOR + SEEDS_PER_TRAIN_SEED * train_seed
    return list(range(first, first + n))


def evaluate(make_env: Callable[[], Env], agents: Mapping[str, Agent], spec: EvalSpec) -> ScoreSet:
    """Play `spec.n_games` greedy games with one agent per team, scoring `spec.team`."""
    env = make_env()
    scores: list[float] = []
    games: list[GameRecording] = []
    for i, seed in enumerate(eval_seeds(spec.train_seed, spec.n_games)):
        score, game = _play(env, agents, seed, team=spec.team, record=i < spec.record)
        scores.append(score)
        if game is not None:
            games.append(game)
    return ScoreSet(
        player=spec.player,
        train_seed=spec.train_seed,
        scores=np.array(scores, dtype=np.float64),
        games=tuple(games),
    )


def _play(

    frames = [env.frame()] if record else []
    rewards: list[float] = []

    over = False
    while not over:

        result = env.step(actions)
        obs, info = result.obs, result.info
        over = result.terminated or result.truncated

def train(

    agents: Mapping[str, Agent],
    settings: RunSettings,
    *,
    root: Path = Path("runs"),

def learning_teams(settings: RunSettings) -> list[str]:
    """The teams that learn: `SOLO` in a single-team run, else those `opponents` marks `learn`."""
    if not settings.opponents:
        return [SOLO]
    return [team for team, role in settings.opponents.items() if role == "learn"]


def _run_steps(
    make_env: Callable[[], Env],
    agents: Mapping[str, Agent],
    settings: RunSettings,
    writer: RunWriter,
) -> None:
    """The step loop: act for every team, then each learning team learns from its Transition."""
    learners = learning_teams(settings)
    spec = EvalSpec(settings.name, settings.seed, team=learners[0], n_games=settings.eval_games)
    env = make_env()
    rng = np.random.default_rng(settings.seed)
    start = last_print = monotonic()
    games = 0
    obs, _ = env.reset(int(rng.integers(TRAINING_SEEDS)))
    active = _all_active(obs)
    for step in range(settings.steps):
        if step % settings.eval_every == 0:
            score = _mean_score(make_env, agents, spec)
            writer.add_point(CurvePoint(step, games, score, monotonic() - start))
        result = _step_and_learn(env, agents, learners, obs, active=active)
        if result.terminated or result.truncated:
            games += 1
            obs, _ = env.reset(int(rng.integers(TRAINING_SEEDS)))
            active = _all_active(obs)
        else:
            obs = result.obs
            active = {team: ~done for team, done in result.done.items()}
        if monotonic() - last_print >= PROGRESS_EVERY_S:
            last_print = monotonic()
            print(_progress(settings, step + 1, games, last_print - start), flush=True)
    score = _mean_score(make_env, agents, spec)
    writer.add_point(CurvePoint(settings.steps, games, score, monotonic() - start))


def _step_and_learn(
    env: Env,
    agents: Mapping[str, Agent],
    learners: list[str],
    obs: Mapping[str, np.ndarray],
    *,
    active: Mapping[str, np.ndarray],
) -> StepResult:
    """Every team acts (exploring), the env steps, then each learner learns from its step."""
    actions = {team: agents[team].act(obs[team], explore=True) for team in env.teams}
    result = env.step(actions)
    for team in learners:
        agents[team].learn(_transition(team, obs, actions, result, active=active[team]))
    return result


def _all_active(obs: Mapping[str, np.ndarray]) -> dict[str, np.ndarray]:
    return {team: np.ones(len(batch), dtype=np.bool_) for team, batch in obs.items()}


def _transition(
    team: str,
    obs: Mapping[str, np.ndarray],
    actions: Mapping[str, np.ndarray],
    result: StepResult,
    *,
    active: np.ndarray,
) -> Transition:
    """One team's batch-first step; agents done only by truncation are not terminated."""
    return Transition(
        obs=obs[team],
        actions=actions[team],
        reward=result.reward[team],
        next_obs=result.obs[team],
        terminated=result.done[team] & active & (not result.truncated),
        active=active,
        truncated=result.truncated,
    )

@dataclass(frozen=True)
class EnvRecording:

    teams: dict[str, TeamSpec]

class ReplayEnv(Env):
    """Serves a recording: `reset` rewinds to its start, `step` returns the next result.

    `step` validates the actions as the contract says (`ValueError`) and raises `RuntimeError`
    once the recorded game is over or before the first `reset`.
    """

    def __init__(self, recording: EnvRecording) -> None:
        self.teams = recording.teams
        self.board = recording.board
        self.recording = recording
        self._t = -1

    def reset(self, seed: int) -> tuple[dict[str, np.ndarray], dict[str, float]]:
        self._t = 0
        return {k: v.copy() for k, v in self.recording.obs.items()}, dict(self.recording.info)

    def step(self, actions: Mapping[str, np.ndarray]) -> StepResult:
        if not 0 <= self._t < len(self.recording.results):
            raise RuntimeError("step called while no game is running")
        check_actions(self.teams, actions)
        result = self.recording.results[self._t]
        self._t += 1
        return result

    def frame(self) -> np.ndarray:
        if self._t <= 0:
            return self.recording.start_frame.copy()
        return self.recording.frames[self._t - 1].copy()


def check_actions(teams: Mapping[str, TeamSpec], actions: Mapping[str, np.ndarray]) -> None:
    """`ValueError` for a missing team, a wrong shape, an out-of-range or non-finite action."""
    for team, spec in teams.items():
        if team not in actions:
            raise ValueError(f"no actions for team {team!r}")
        action = np.asarray(actions[team])
        space = spec.actions
        shape = (spec.n_agents,) if space.kind == "discrete" else (spec.n_agents, space.dim)
        if action.shape != shape:
            raise ValueError(f"team {team!r}: actions shaped {action.shape}, expected {shape}")
