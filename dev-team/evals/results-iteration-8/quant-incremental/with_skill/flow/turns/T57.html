# Reference Intake Examples

The index template, the subagent prompt, then the GridLoad worked example: three files arrive while stage S2 is being specced.

`dt` below means `python3 ../../scripts/dt.py`, run from the project root.

---

## Index template: `docs/references.md`

````markdown
# <Project> — References

**Status:** Draft · **Last updated:** YYYY-MM-DD

### RF-01: <What the file is, in a few words>
**File:** `references/<file>` · **Hash:** — · **Kind:** code · **Milestones:** S<n>
- **Purpose:** <what it is for, one line>
- **Key parts:** `<function>(<args>)`, `<Class>`, … (the parts a builder would look at)
- **In → Out:** <input shape or type> → <output shape or type>
- **Use for:** <the step, case or decision it can inform; PL or TC IDs once they exist>
- **Caveats:** <what not to reuse as is, or "none found">

## Retired
````

- **Hash** stays `—` until `dt references --stamp` writes the first 8 hex digits of the file's sha256. A later mismatch puts the file under `references_changed`.
- **Kind** is `code` or `doc`.
- **Milestones** holds stage IDs `S<n>` (or `M<n>` for one slice of a cut stage; comma-separated), `all`, or `—`.
- **Retired** holds one struck line per removed file: `- ~~RF-04: Old loader~~ Retired 2026-12-01: file removed; superseded by RF-05`. Omit the heading until the first file is retired.

### RF-02: Sequence-model training windows
**File:** `references/tft_dataset.py` · **Hash:** fdf31b69 · **Kind:** code · **Milestones:** —
- **Purpose:** turns a long (ticker, date) panel into fixed-length encoder/decoder windows for a temporal-fusion-transformer-style forecaster. Inputs are split into static, known and observed, and the windows are split by date.
- **Key parts:** `WindowSpec` (lookback 63, horizon 5, stride 1), `add_calendar_features`, `encode_static`, `normalise_observed(window=252)`, `build_windows`, `split_by_origin`
- **In → Out:** a long DataFrame plus targets → arrays: static (S, n), known (S, L+H, n), observed (S, L, n), target (S, H, n), origin, ticker. These are then split into train/valid/test.
- **Use for:** the windowing and date-split step of a sequence-model forecaster.
- **Caveats:**
  - **No embargo between splits:** the last training windows' targets fall inside validation, which is leakage.
  - **Vocabulary from the full sample:** `encode_static` builds it on the whole panel, and a category it hasn't seen breaks the int cast.
  - **Survivorship bias:** there is no point-in-time membership filter.
  - **Silent data loss:** short tickers and unmatched rows are dropped silently, and windows bridge date gaps.
  - **Hidden missing data:** NaN is filled with 0, which hides gaps and the warm-up period.
  - **Smaller issues:**
    - static values come from each ticker's first row
    - the calendar ignores holidays
    - stride-1 copies are memory-heavy
    - defaults are hard-coded

- **In → Out:** (ticker, date, adj_close) → (ticker, date, `fwd_ret_{h}d`, `fwd_vol_{h}d`)
- **Use for:** the label step of a forecaster; label-alignment and embargo test cases.
- **Caveats:**

  - **Row counting:** horizons count rows, not trading days, so a gap stretches the window.

  - **Crude demeaning:** `demean_cross_section` averages over whatever tickers are present, not point-in-time members, and is no factor adjustment.
