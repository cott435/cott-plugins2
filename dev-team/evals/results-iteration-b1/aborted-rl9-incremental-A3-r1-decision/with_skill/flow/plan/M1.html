Waves

Left to right is the order work can start: a task sits in the first wave after everything it depends on. Rows are task kinds. An interface task is a diamond; dashed edges are what it unblocks. Solid edges are other depends; a split task is two boxes, the tester (dashed border) then the implementer. A tester waits only on the interface: the interface tasks among its task's ancestors, else all of the milestone's. Waves count boxes, so a split task can take two. The critical path is the thick line and the bold boxes; ✓ is done. Edges an interface mitigates do not order the tasks and are listed below, not drawn.
