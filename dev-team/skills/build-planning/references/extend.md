# Extend

`dt status` says `extend`: a stage is newly designed (`stage_to_cut`), or the next milestone needs a plan. Example: `examples-routing.md` (a milestone with stage skills and references).

1. **Grow check, then cut the stage:** `cut.md` steps 1–2.
2. **Plan the next milestone at kickoff**, in `tasks/queued/` only if the user asks; never merge it into the active plan. Scope it (`cut.md` step 3), shape it (`phase0.md`), then write its tasks and files (`tasks.md`).
3. Run the Review Gate.
