The ID survives Grow, because the component id becomes the package id.

10	- **Type sections.** Every type one step hands to another, and every type a public signature takes or returns, is its own section with the title `type`: `### profile.Profile: type`. The first line is its shape as code: a frozen dataclass's fields, a `typing.Protocol`, or a pandera schema's columns for a dataframe. Then **Invariants** and **Used by**. `pipeline-design` names these types in every step's `In → Out`; the build's interface task writes them, as code, into the owner's `types.py`. Freeze only what crosses: a helper's or a private function's types stay out.

Every type that crosses step owners has one, components included: consumers are packages, components, or both.
