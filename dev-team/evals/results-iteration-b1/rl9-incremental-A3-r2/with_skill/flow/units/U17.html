89	### AD-03: Own environment protocol, shaped like Gymnasium
90	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** `core`
91	- **Context:** CORE-01 needs one interface for every environment. REF-01 needs the library agent to train on the same Snake. AGENT-06 keeps library code out of the lab's agents.
92	- **Decision:** `core.Env` is a small Protocol whose `reset(seed)` returns `(obs, info)` and whose `step(actions)` returns a `StepResult` with Gymnasium's fields (observation, reward, terminated, truncated, info), plus `frame()` for replay. AD-09 sets their batch-first shape over agents. `reference` wraps one single-agent team of a `core.Env`, with every other team played by a frozen agent (AD-15), in a `gymnasium.Env` adapter.
93	- **Alternatives:** Subclass `gymnasium.Env` directly — no adapter, but every environment and the core then depend on Gymnasium. A bespoke interface unlike Gymnasium's — needs a bigger adapter and teaches a nonstandard shape.
94	- **Consequences:** Truncation (starvation or the step cap) and termination (a collision or a catch) stay separate, so learning targets bootstrap correctly on truncation. The adapter is checked with Stable-Baselines3's `check_env`.

97	### AD-04: Stable-Baselines3 DQN as the reference implementation
98	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** `reference`
99	- **Context:** For Snake, REF-01–REF-03 need an established implementation trained with the same view, rewards, step budget and seeds as the compact-view neural agent; AD-10 covers the tank. The Stable-Baselines3 DQN docs (https://stable-baselines3.readthedocs.io/en/master/modules/dqn.html, read 2026-10-17) say it supports Discrete actions and Box observations, has `buffer_size`, `target_update_interval`, `exploration_fraction`, `seed` and `device`, and offers `MlpPolicy` for vector observations. The custom-environment guide (https://stable-baselines3.readthedocs.io/en/master/guide/custom_env.html, read 2026-10-17) requires a `gymnasium.Env` with `reset(seed, options) → (obs, info)` and a five-field `step`, checked by `check_env`.
100	- **Decision:** `reference` trains Stable-Baselines3 DQN with `MlpPolicy` on the compact view through the AD-03 adapter, with `device="cpu"`. Its hidden layers, learning rate, discount, batch size, memory size, target interval and exploration schedule are mapped one-to-one from the same `RunSettings` the hand-written agent uses. Its curve points come from `evaluate`, exactly as the lab's own agents' do.
101	- **Alternatives:** CleanRL's single-file DQN — very readable, but a script to copy rather than a library to call, so "matching" it blurs into copying it. RLlib — far heavier than one laptop needs.
102	- **Consequences:** Stable-Baselines3 measures exploration as a fraction of training rather than in decay steps, and updates every `train_freq` steps. The mapping fixes `train_freq=1` and `gradient_steps=1`, and sets `exploration_fraction = decay_steps / steps`. Stable-Baselines3 and Gymnasium are an optional install extra, so the rest of the lab never carries them.
103	- **Probe:** none — the two pages above settle the spaces, parameters and environment interface. No account or plan is involved.

class ReplayEnv(Env):
    """Serves a recording: `reset` rewinds to its start, `step` returns the next result.

    `step` validates the actions as the contract says (`ValueError`) and raises `RuntimeError`
    once the recorded game is over or before the first `reset`.
    """

    def __init__(self, recording: EnvRecording) -> None:
        self.teams = recording.teams
        self.board = recording.board
        self.recording = recording
        self._t = -1

    def reset(self, seed: int) -> tuple[dict[str, np.ndarray], dict[str, float]]:
        self._t = 0
        return {k: v.copy() for k, v in self.recording.obs.items()}, dict(self.recording.info)

    def step(self, actions: Mapping[str, np.ndarray]) -> StepResult:
        if not 0 <= self._t < len(self.recording.results):
            raise RuntimeError("step called while no game is running")
        check_actions(self.teams, actions)
        result = self.recording.results[self._t]
        self._t += 1
        return result

    def frame(self) -> np.ndarray:
        if self._t <= 0:
            return self.recording.start_frame.copy()
        return self.recording.frames[self._t - 1].copy()


def check_actions(teams: Mapping[str, TeamSpec], actions: Mapping[str, np.ndarray]) -> None:
    """`ValueError` for a missing team, a wrong shape, an out-of-range or non-finite action."""
    for team, spec in teams.items():
        if team not in actions:
            raise ValueError(f"no actions for team {team!r}")
        action = np.asarray(actions[team])
        space = spec.actions
        shape = (spec.n_agents,) if space.kind == "discrete" else (spec.n_agents, space.dim)
        if action.shape != shape:
            raise ValueError(f"team {team!r}: actions shaped {action.shape}, expected {shape}")
        if not np.all(np.isfinite(action)):
            raise ValueError(f"team {team!r}: non-finite action")
        if space.kind == "discrete" and not np.all((action >= 0) & (action < space.n)):
            raise ValueError(f"team {team!r}: action outside 0..{space.n - 1}")

"""runs.RunWriter: an in-memory double, and the check any run writer must pass.

`check_writer(writer, run, agent)` takes the provider, so the writer `runs.create_run`
returns runs the same check as the double.
"""

from collections.abc import Sequence
from dataclasses import dataclass
from pathlib import Path
from typing import Literal

import numpy as np

from rllab.core import SOLO, Agent, RunSettings
from rllab.runs import CurvePoint, GameRecording, RunRecord, RunWriter


@dataclass(frozen=True)
class WriterRun:
    """What one recorded run handed its writer: settings, curve points and games."""

    settings: RunSettings
    points: tuple[CurvePoint, ...]
    games: tuple[GameRecording, ...]


class MemoryRunWriter:
    """Keeps every call in memory; agents save their checkpoints and generations under `path`."""

    def __init__(self, path: Path, settings: RunSettings) -> None:
        self.path = path
        self.settings = settings
        self.points: list[CurvePoint] = []
        self.checkpoints: dict[str, Path] = {}
        self.generations: dict[str, list[Path]] = {}
        self.games: tuple[GameRecording, ...] = ()
        self.status = "running"

    def add_point(self, p: CurvePoint) -> None:
        self.points.append(p)

    def save_checkpoint(self, agent: Agent, *, team: str = SOLO) -> None:
        path = self.path / f"checkpoint-{team}"
        agent.save(path)
        self.checkpoints[team] = path

    def save_generation(self, agent: Agent, *, team: str, index: int) -> Path:
        path = self.path / "generations" / team / str(index)
        path.parent.mkdir(parents=True, exist_ok=True)
        agent.save(path)
        self.generations.setdefault(team, []).append(path)
        return path

    def save_games(self, games: Sequence[GameRecording]) -> None:
        self.games = tuple(games)

    def finish(self, status: Literal["complete", "incomplete"]) -> RunRecord:
        self.status = status
        return RunRecord(
            path=self.path,
            settings=self.settings,
            curve=tuple(self.points),
            status=status,
            checkpoints=dict(self.checkpoints),
            generations={team: tuple(paths) for team, paths in self.generations.items()},
            games=self.games,
        )


def check_writer(writer: RunWriter | MemoryRunWriter, run: WriterRun, agent: Agent) -> RunRecord:
    """A run written point by point, with a checkpoint and games, finishes as one RunRecord."""
    for point in run.points:
        writer.add_point(point)
    writer.save_checkpoint(agent)
    writer.save_games(run.games)
    record = writer.finish("complete")
    assert isinstance(record, RunRecord)
    assert record.status == "complete"
    assert record.settings == run.settings
    assert record.curve == run.points
    assert set(record.checkpoints) == {SOLO}
    assert len(record.games) == len(run.games)
    for got, sent in zip(record.games, run.games, strict=True):
        np.testing.assert_array_equal(got.frames, sent.frames)
    return record

    evaluate: Evaluate,

class SoloGymEnv(gym.Env[np.ndarray, np.int64]):

        self.observation_space = gym.spaces.Box(-np.inf, np.inf, spec.obs_shape, np.float32)
        self.action_space = gym.spaces.Discrete(spec.actions.n)

        self, *, seed: int | None = None, options: dict[str, Any] | None = None
    ) -> tuple[np.ndarray, dict[str, Any]]:

        super().reset(seed=seed)
        obs, info = self.env.reset(int(self.np_random.integers(TRAIN_SEEDS)))

def train_reference(settings: RunSettings, *, root: Path = Path("runs")) -> RunRecord:
    """Train the library agent on the settings' environment, with the same curve points."""
    make_env = reference_env(settings)
    writer = create_run(settings, root=root)
    model = DQN(
        "MlpPolicy", SoloGymEnv(make_env()), seed=settings.seed, device="cpu", **dqn_kwargs(settings)
    )
    curve = CurveCallback(make_env, ModelAgent(model), settings, writer)
    curve.add_point(0)
    model.learn(total_timesteps=settings.steps, callback=curve)
    writer.save_checkpoint(ModelAgent(model), team=SOLO)
    return writer.finish("complete")


def reference_env(settings: RunSettings) -> Callable[[], Env]:
    """The environment factory for settings the reference supports; `ValueError` otherwise."""
    if settings.agent != "reference":
        raise ValueError(f"train_reference needs agent 'reference', got {settings.agent!r}")
    if settings.env != "snake" or settings.view != "compact":
        raise ValueError(f"the reference cannot train {settings.env}/{settings.view}")
    return lambda: Snake(view="compact", rewards=settings.rewards)

class LineEnv(Env):
    """Five steps per game; action 0 scores a point; obs is the seed's first digit and the step."""

    board: Literal["grid", "tank"] = "grid"

    def __init__(self) -> None:
        self.teams = {SOLO: TeamSpec(1, (OBS,), ActionSpace("discrete", n=3))}
        self.seeds: list[int] = []
        self.actions: list[np.ndarray] = []
        self.t = 0
        self.score = 0.0

    def _obs(self) -> dict[str, np.ndarray]:
        obs = np.zeros((1, OBS), dtype=np.float32)
        obs[0, 0] = self.t
        return {SOLO: obs}

    def _info(self) -> dict[str, float]:
        return {"steps": float(self.t), "score": self.score, f"score:{SOLO}": self.score}

    def reset(self, seed: int) -> tuple[dict[str, np.ndarray], dict[str, float]]:
        self.seeds.append(seed)
        self.t, self.score = 0, 0.0
        return self._obs(), self._info()

    def step(self, actions: Mapping[str, np.ndarray]) -> StepResult:
        self.actions.append(actions[SOLO])
        self.t += 1
        reward = 1.0 if int(actions[SOLO][0]) == 0 else 0.0
        self.score += reward
        return StepResult(
            obs=self._obs(),
            reward={SOLO: np.array([reward], dtype=np.float32)},
            done={SOLO: np.array([self.t >= GAME_STEPS])},
            terminated=self.t >= GAME_STEPS,
            truncated=False,
            info=self._info(),
        )

    def frame(self) -> np.ndarray:
        return np.zeros((3, 3), dtype=np.int8)


class MemoryWriter:
    """Keeps the curve and saves the checkpoint through the agent, as `RunWriter` does."""

    def __init__(self, path: Path, settings: RunSettings) -> None:
        self.path = path
        self.settings = settings
        self.points: list[CurvePoint] = []
        self.checkpoints: dict[str, Path] = {}

    def add_point(self, p: CurvePoint) -> None:
        self.points.append(p)

    def save_checkpoint(self, agent: Agent, *, team: str = SOLO) -> None:
        path = self.path / f"checkpoint-{team}"
        agent.save(path)
        self.checkpoints[team] = path

    def finish(self, status: Literal["complete", "incomplete"]) -> RunRecord:
        return RunRecord(self.path, self.settings, tuple(self.points), status, self.checkpoints, {}, ())
