# Reference Intake Examples

The index template, the subagent prompt, then the GridLoad worked example: three files arrive while stage S2 is being specced.

## Index template: `docs/references.md`

````markdown
# <Project> — References

**Status:** Draft · **Last updated:** YYYY-MM-DD

### RF-01: <What the file is, in a few words>
**File:** `references/<file>` · **Hash:** — · **Kind:** code · **Milestones:** S<n>
- **Purpose:** <what it is for, one line>
- **Key parts:** `<function>(<args>)`, `<Class>`, … (the parts a builder would look at)
- **In → Out:** <input shape or type> → <output shape or type>
- **Use for:** <the step, case or decision it can inform; PL or TC IDs once they exist>
- **Caveats:** <what not to reuse as is, or "none found">

## Retired
````

- **Hash** stays `—` until `dt references --stamp` writes the first 8 hex digits of the file's sha256. A later mismatch puts the file under `references_changed`.
- **Kind** is `code` or `doc`.
- **Milestones** holds stage IDs `S<n>` (or `M<n>` for one slice of a cut stage; comma-separated), `all`, or `—`.
- **Retired** holds one struck line per removed file: `- ~~RF-04: Old loader~~ Retired 2026-12-01: file removed; superseded by RF-05`. Omit the heading until the first file is retired.

### RF-01: PCA market-mode removal
**File:** `references/market_decomposition.py` · **Hash:** b3993e95 · **Kind:** code · **Milestones:** —
- **Purpose:** removes the top-k principal components (the market mode) from a daily returns panel, leaving residual returns, and measures how much cross-correlation remains
- **Key parts:** `demean_returns(returns, min_obs)`, `standardise(returns)`, `pca_factors(returns, k)`, `residualize(returns, factors)`, `remove_market(returns, k)`, `residual_correlation_check(residuals)`
- **In → Out:** T×N DataFrame of simple daily returns → residuals (T×N), loadings and betas (N×k), factors (T×k), explained share (k), mean |off-diagonal| residual correlation
- **Use for:** the PCA factor-removal step of the return-structure stage; a known-answer test case with one planted factor (PC1 should explain a large share, residual correlation should be near zero)
- **Caveats:**
  - It fits the demeaning, scaling, eigenvectors and betas on the whole panel, which is look-ahead; the project must fit per window.
  - It drops columns with fewer than 60 observations without saying so, and fills the remaining gaps with 0. That invents flat days for names not yet listed or already delisted.
  - It has no guard for zero-variance columns.
  - The betas mix units: raw returns are regressed on factors built from standardised returns.
  - Fixing each component's sign by its column sum is arbitrary when k > 1.
