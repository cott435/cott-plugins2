### core.Env: type
```python
class Env(Protocol):
    n_agents: int
    obs_shape: tuple[int, ...]
    actions: ActionSpace
    board: Literal["grid", "tank"]
    def reset(self, seed: int) -> tuple[np.ndarray, dict[str, float]]: ...
    def step(self, actions: np.ndarray) -> StepResult: ...
    def frame(self) -> np.ndarray: ...
```
- **Invariants:** batch-first (AD-09): observations are float32 `(n_agents, *obs_shape)`, and `actions` is `(n_agents,)` int64 when discrete or `(n_agents, dim)` float32 when continuous. Entries for agents already done are ignored. `info` always holds `score` and `steps`. `frame()` is an int8 grid of cell codes (0 empty, 1 head, 2 body, 3 food or goal) when `board == "grid"`, and a `(K, 4)` float32 array of circles `(x, y, radius, kind)` when `board == "tank"` (AD-12). The same seed and actions give the same results.
- **Errors:** `RuntimeError` if `step` is called after the game is over. `ValueError` for an action of the wrong shape, outside the discrete range, or non-finite.
- **Boundary:** train, evaluate, reference, lab · **Fixtures:** tests/contracts/core.Env/ · **Cases:** a recorded 20-step Snake game ending in a wall hit; a recorded 9-step corridor game reaching the goal; a recorded 30-step 8-fish tank game with 2 catches
