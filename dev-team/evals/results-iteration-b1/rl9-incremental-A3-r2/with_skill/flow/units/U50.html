92	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** `core`

99	### AD-04: Stable-Baselines3 DQN as the reference implementation
100	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** `reference`
101	- **Context:** For Snake, REF-01–REF-03 need an established implementation trained with the same view, rewards, step budget and seeds as the compact-view neural agent; AD-10 covers the tank. The Stable-Baselines3 DQN docs (https://stable-baselines3.readthedocs.io/en/master/modules/dqn.html, read 2026-10-17) say it supports Discrete actions and Box observations, has `buffer_size`, `target_update_interval`, `exploration_fraction`, `seed` and `device`, and offers `MlpPolicy` for vector observations. The custom-environment guide (https://stable-baselines3.readthedocs.io/en/master/guide/custom_env.html, read 2026-10-17) requires a `gymnasium.Env` with `reset(seed, options) → (obs, info)` and a five-field `step`, checked by `check_env`.
102	- **Decision:** `reference` trains Stable-Baselines3 DQN with `MlpPolicy` on the compact view through the AD-03 adapter, with `device="cpu"`. Its hidden layers, learning rate, discount, batch size, memory size, target interval and exploration schedule are mapped one-to-one from the same `RunSettings` the hand-written agent uses. Its curve points come from `evaluate`, exactly as the lab's own agents' do.
103	- **Alternatives:** CleanRL's single-file DQN — very readable, but a script to copy rather than a library to call, so "matching" it blurs into copying it. RLlib — far heavier than one laptop needs.
104	- **Consequences:** Stable-Baselines3 measures exploration as a fraction of training rather than in decay steps, and updates every `train_freq` steps. The mapping fixes `train_freq=1` and `gradient_steps=1`, and sets `exploration_fraction = decay_steps / steps`. Stable-Baselines3 and Gymnasium are an optional install extra, so the rest of the lab never carries them.
105	- **Probe:** none — the two pages above settle the spaces, parameters and environment interface. No account or plan is involved.

from collections.abc import Mapping

import gymnasium as gym
import numpy as np

from rllab.core import SOLO, Agent, Env

TRAINING_SEEDS = 1_000_000
"""Game seeds stay below every evaluation seed (DATA-01)."""


class GymAdapter(gym.Env[np.ndarray, np.ndarray | int]):
    """`team`'s one agent as a `gymnasium.Env`: unbatched observations, one action.

    Every other team is played by its frozen agent in `others`, greedily (AD-15). Each reset
    starts a game on the next seed drawn from a generator seeded by the latest
    `reset(seed=...)`, so the same seed gives the same games.
    """

    def __init__(
        self, env: Env, *, team: str = SOLO, others: Mapping[str, Agent] | None = None
    ) -> None:
        others = dict(others or {})
        if team not in env.teams:
            raise ValueError(f"team {team!r} is not one of {sorted(env.teams)}")
        spec = env.teams[team]
        if spec.n_agents != 1:
            raise ValueError(f"the adapter needs team {team!r} to have one agent, got {spec}")
        missing = sorted(set(env.teams) - {team} - set(others))
        if missing:
            raise ValueError(f"no frozen agent in `others` for teams {missing}")
        self.env = env
        self.team = team
        self.others = others
        self.observation_space = gym.spaces.Box(0.0, 1.0, shape=spec.obs_shape, dtype=np.float32)
        self.action_space: gym.spaces.Space[np.ndarray | int]
        if spec.actions.kind == "discrete":
            self.action_space = gym.spaces.Discrete(spec.actions.n)
        else:
            self.action_space = gym.spaces.Box(-1.0, 1.0, shape=(spec.actions.dim,), dtype=np.float32)
        self._games = np.random.default_rng(0)
        self._obs: dict[str, np.ndarray] = {}

    def reset(
        self, *, seed: int | None = None, options: dict[str, object] | None = None
    ) -> tuple[np.ndarray, dict[str, float]]:
        super().reset(seed=seed)
        if seed is not None:
            self._games = np.random.default_rng(seed)
        self._obs, info = self.env.reset(int(self._games.integers(TRAINING_SEEDS)))
        return self._obs[self.team][0], dict(info)

    def step(self, action: np.ndarray | int) -> tuple[np.ndarray, float, bool, bool, dict[str, float]]:
        actions = {name: agent.act(self._obs[name], explore=False) for name, agent in self.others.items()}
        actions[self.team] = self._batched(action)
        result = self.env.step(actions)
        self._obs = result.obs
        reward = float(result.reward[self.team][0])
        return self._obs[self.team][0], reward, result.terminated, result.truncated, dict(result.info)

    def _batched(self, action: np.ndarray | int) -> np.ndarray:
        """The learner's one action with the batch axis the env expects."""
        if isinstance(self.action_space, gym.spaces.Discrete):
            return np.array([int(action)], dtype=np.int64)
        return np.asarray(action, dtype=np.float32).reshape(1, -1)

class ReplayGym(gym.Env[np.ndarray, Any]):
    """Serves a recording: `reset` rewinds to its start, `step` returns the next result.

    `step` raises `RuntimeError` once the recorded game is over or before the first `reset`.
    """

    def __init__(self, recording: GymRecording) -> None:
        self.recording = recording
        self.observation_space = gym.spaces.Box(
            0.0, 1.0, shape=recording.obs_shape, dtype=np.float32
        )
        self.action_space = gym.spaces.Discrete(recording.n_actions)
        self._t = -1

    def reset(
        self, *, seed: int | None = None, options: dict[str, object] | None = None
    ) -> tuple[np.ndarray, dict[str, float]]:
        super().reset(seed=seed)
        self._t = 0
        return self.recording.obs.copy(), dict(self.recording.info)

    def step(self, action: np.ndarray | int) -> tuple[np.ndarray, float, bool, bool, dict[str, float]]:
        r, t = self.recording, self._t
        if not 0 <= t < len(r.actions):
            raise RuntimeError("step called while no game is running")
        self._t += 1
        return r.observations[t].copy(), r.rewards[t], r.terminated[t], r.truncated[t], dict(r.infos[t])
