34	### AD-05: Seeds from SeedSequence, disjoint held-out ranges, one process per run
35	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** system
36	- **Context:** WORLD-01, WORLD-02, TRAIN-02 and REPLAY-02 need exact repeats; TRAIN-04 and EVAL-03 need seeds never used in training; TRAIN-05 and QR-02 need runs in parallel, one per core.
37	- **Decision:** A run seed spawns the learner's, exploration and episode-seed generators through `np.random.SeedSequence`. An episode seed spawns the world's and the policies' generators inside `core.play_episode`. Training draws episode seeds from [0, 10⁶); evaluation seeds are the fixed `core.EVAL_SEEDS` and `core.FINAL_SEEDS` ranges (see Data). `train.run_batch` runs each config in its own `spawn` process with `torch.set_num_threads(1)` and `torch.use_deterministic_algorithms(True)`.
38	- **Alternatives:** Global `np.random.seed`/`torch.manual_seed`: order-dependent, breaks once evaluation interleaves with training. Threads: the GIL serialises the Python world loop.
39	- **Consequences:** Identical runs are promised on the same machine only (TRAIN-02). In-training evaluation never touches the training generators, so turning evaluation off for a test leaves training identical.

42	### AD-06: Run folders of JSON, JSON Lines and torch checkpoints
43	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** system
44	- **Context:** LOG-01 and LOG-02 need a record and per-episode logs. LOG-06 needs them readable while the run writes, at most one evaluation point behind. A stopped run keeps its checkpoints and is marked incomplete. A run name that already exists is refused (TRAIN edge cases). REPLAY edge cases need a checkpoint to carry its world spec.
45	- **Decision:** One folder per run (see Data). Logs are append-only JSON Lines, flushed at every evaluation point; `run.json` is rewritten atomically (write, then rename) on each status change. A checkpoint is a `torch.save` dict of spec, method configs and state dicts, loaded with `weights_only=True`.
46	- **Alternatives:** Parquet: fast to read but not appendable while a run is live. SQLite: one file for everything, but concurrent writers from parallel runs need care and the files are no longer readable by eye.
47	- **Consequences:** Charts and evaluation read whole JSONL files; at ~10⁴ episodes per run that is instant. A crashed process leaves `run.json` at `running`; `runlog` reports any `running` run with no live process as incomplete.

def errors(instance: Any, rules: Mapping[str, Any], where: str = "$") -> list[str]:
    """Every way `instance` breaks `rules`: type, enum, const, minimum, maximum, minItems,
    maxItems, items, properties, required, additionalProperties, anyOf, and `$ref` to another
    folder's schema by name (`"$ref": "core.TeamSpec"`, or one of its properties with
    `"$ref": "core.Policy#calls"`)."""
    if "$ref" in rules:
        folder, _, prop = rules["$ref"].partition("#")
        target = schema(folder)
        return errors(instance, target["properties"][prop] if prop else target, where)
    if "anyOf" in rules:
        if all(errors(instance, option, where) for option in rules["anyOf"]):
            return [f"{where}: matches no anyOf option"]
        return []
    if "type" in rules and not _type_ok(instance, rules["type"]):
        return [f"{where}: {instance!r} is not {rules['type']}"]
    found = _value_errors(instance, rules, where)
    if isinstance(instance, list):
        found += _array_errors(instance, rules, where)
    if isinstance(instance, dict):
        found += _object_errors(instance, rules, where)
    return found


def _type_ok(instance: Any, wanted: str | list[str]) -> bool:
    names = [wanted] if isinstance(wanted, str) else wanted
    if isinstance(instance, bool):
        return "boolean" in names
    return any(isinstance(instance, _JSON_TYPES[n]) for n in names)


def _value_errors(instance: Any, rules: Mapping[str, Any], where: str) -> list[str]:
    found = []
    if "enum" in rules and instance not in rules["enum"]:
        found.append(f"{where}: {instance!r} not in {rules['enum']}")
    if "const" in rules and instance != rules["const"]:
        found.append(f"{where}: {instance!r} != {rules['const']!r}")
    if "minimum" in rules and instance < rules["minimum"]:
        found.append(f"{where}: {instance!r} < {rules['minimum']}")
    if "maximum" in rules and instance > rules["maximum"]:
        found.append(f"{where}: {instance!r} > {rules['maximum']}")
    return found


def _array_errors(instance: list[Any], rules: Mapping[str, Any], where: str) -> list[str]:
    found = []
    if len(instance) < rules.get("minItems", 0):
        found.append(f"{where}: fewer than {rules['minItems']} items")
    if len(instance) > rules.get("maxItems", len(instance)):
        found.append(f"{where}: more than {rules['maxItems']} items")
    for i, item in enumerate(instance):
        found += errors(item, rules.get("items", {}), f"{where}[{i}]")
    return found


def _object_errors(instance: dict[str, Any], rules: Mapping[str, Any], where: str) -> list[str]:
    props = rules.get("properties", {})
    found = [f"{where}: missing {k!r}" for k in rules.get("required", []) if k not in instance]
    for key, value in instance.items():
        if key in props:
            found += errors(value, props[key], f"{where}.{key}")
        elif rules.get("additionalProperties", True) is False:
            found.append(f"{where}: unexpected {key!r}")
        elif isinstance(rules.get("additionalProperties"), dict):
            found += errors(value, rules["additionalProperties"], f"{where}.{key}")
    return found

def decode(tp: Any, data: Any) -> Any:
    """`data` (parsed JSON) as an instance of the contract type `tp`; TypeError if it isn't one."""
    if isinstance(tp, typing.TypeAliasType):
        tp = tp.__value__
    if tp is Any or tp is object:
        return data
    decoder = next((d for test, d in _DECODERS if test(tp)), _decode_scalar)
    return decoder(tp, data)


def _decode_dataclass(tp: type, data: Any) -> Any:
    fields = {f.name: f for f in dataclasses.fields(tp)}
    required = {
        n
        for n, f in fields.items()
        if f.default is dataclasses.MISSING and f.default_factory is dataclasses.MISSING
    }
    if not isinstance(data, dict) or not required <= data.keys() <= fields.keys():
        raise TypeError(f"{tp.__name__} needs an object of {sorted(fields)}, got {data!r}")
    hints = typing.get_type_hints(tp)
    return tp(**{k: decode(hints[k], v) for k, v in data.items()})


def _decode_union(tp: Any, data: Any) -> Any:
    options = typing.get_args(tp)
    if data is None and type(None) in options:
        return None
    problems = []
    for option in (o for o in options if o is not type(None)):
        try:
            return decode(option, data)
        except TypeError as exc:
            problems.append(str(exc))
    raise TypeError(f"{data!r} matches no option: {problems}")


def _decode_literal(tp: Any, data: Any) -> Any:
    if data not in typing.get_args(tp):
        raise TypeError(f"{data!r} is not one of {typing.get_args(tp)}")
    return data


def _is_array(tp: Any) -> bool:
    """`np.ndarray`, `np.ndarray[...]`, or a subscripted alias of it such as `NDArray[...]`."""
    origin = typing.get_origin(tp)
    if isinstance(origin, typing.TypeAliasType):
        origin = typing.get_origin(origin.__value__)
    return tp is np.ndarray or origin is np.ndarray


def _decode_array(_tp: Any, data: Any) -> np.ndarray[Any, Any]:
    array = np.asarray(data)
    if array.dtype.kind == "f":
        return array.astype(np.float32)
    if array.dtype.kind not in "biu":

def _decode_generic(tp: Any, data: Any) -> Any:
    origin, args = typing.get_origin(tp), typing.get_args(tp)
    is_mapping = isinstance(origin, type) and issubclass(origin, Mapping)
    if not isinstance(data, dict if is_mapping else list):
        raise TypeError(f"{tp!r} can't hold {data!r}")
    if is_mapping:
        return {decode(args[0], k): decode(args[1], v) for k, v in data.items()}
    if origin is list or (len(args) == 2 and args[1] is Ellipsis):
        items = [decode(args[0], d) for d in data]
        return items if origin is list else tuple(items)
    if len(args) != len(data):
        raise TypeError(f"{data!r} does not have {len(args)} items")
    return tuple(decode(a, d) for a, d in zip(args, data, strict=True))


def _decode_scalar(tp: Any, data: Any) -> Any:
    if tp is Path:
        return Path(_checked(str, data))
    if tp is datetime:
        return datetime.fromisoformat(_checked(str, data))
    if tp is timedelta:
        return timedelta(seconds=_checked(float, data))
    if tp is float:
        return float(_checked(float, data))
    if tp in {int, str, bool}:
        return _checked(tp, data)
    raise TypeError(f"no decoder for {tp!r}")


def _checked(tp: type, data: Any) -> Any:

    if (isinstance(data, bool) and tp is not bool) or not (isinstance(data, tp) or numeric):
        raise TypeError(f"{data!r} is not {tp.__name__}")
    return data

"""Replay double of `core.World`: serves one recorded episode.

`reset(seed)` returns the recorded start for any seed (and `result()` reports that seed), so a
training loop can reset it as often as it likes. `step` refuses an action outside `spec.action`
with `ActionError` and a step after `done` with `RuntimeError`, as every World must; any action
inside the action space advances the recording by one step.
"""

from dataclasses import dataclass, field, replace
from typing import Any

import numpy as np

from rllab.core import ActionError, Array, Box, DrawState, EpisodeResult, Step, WorldSpec


def check_actions(spec: WorldSpec, actions: Array, active: Array) -> None:
    """ActionError for the first active agent whose action is outside `spec.action`."""
    for i, row in enumerate(np.asarray(actions)):
        if active[i] and not inside(spec, row):
            raise ActionError(spec.agents[i], row.tolist())


def inside(spec: WorldSpec, action: Array) -> bool:
    if isinstance(spec.action, Box):
        low, high = spec.action.low, spec.action.high
        return action.shape == (spec.action.dims,) and bool(
            np.all((action >= low) & (action <= high))
        )
    return action.shape == () and float(action).is_integer() and 0 <= action < spec.action.n


@dataclass
class ReplayWorld:
    spec: WorldSpec
    steps: list[Step]
    draws: list[DrawState]
    recorded: EpisodeResult
    at: int | None = field(default=None, init=False)
    seed: int = field(default=0, init=False)

    def reset(self, seed: int) -> Step:
        self.at, self.seed = 0, seed
        return self.steps[0]

    def step(self, actions: Array) -> Step:
        if self.at is None or self.steps[self.at].done:
            raise RuntimeError("step before reset or after done")
        check_actions(self.spec, actions, self.steps[self.at].active)
        self.at += 1
        return self.steps[self.at]

    def result(self) -> EpisodeResult:
        return replace(self.recorded, seed=self.seed)

    def draw(self) -> DrawState:
        return self.draws[self.at or 0]


def build(kit: Any, recording: dict[str, Any]) -> ReplayWorld:
    return ReplayWorld(
        kit.decode(WorldSpec, recording["spec"]),
        kit.decode(list[Step], recording["steps"]),
        kit.decode(list[DrawState], recording["draws"]),
        kit.decode(EpisodeResult, recording["result"]),
    )

_CLOSING: dict[str, RunStatus] = {
    "finished": "finished",
    "incomplete": "incomplete",
    "failed": "failed",
}


class RunWriter:
    """Creates `runs/<world>/<variant>/<name>` under `root`; refuses an existing one."""

    def __init__(self, root: Path, config: RunConfig, spec: WorldSpec) -> None:
        self.path = root / config.world / config.variant / config.name
        if self.path.exists():
            raise RunExistsError(self.path)
        (self.path / "checkpoints").mkdir(parents=True)
        self.config = config
        self.spec = spec
        self._episodes: list[EpisodeResult] = []
        self._evals: list[EvalPoint] = []
        self._record = RunRecord(config, spec, datetime.now(), None, "running", None, self.path)
        self._write_record()

    def episode(self, result: EpisodeResult) -> None:
        self._episodes.append(result)

    def eval(self, point: EvalPoint) -> None:
        self._evals.append(point)
        self._flush()

    def checkpoint(self, pct: int, step: int, state: Mapping[str, dict[str, object]]) -> Checkpoint:
        path = self.path / "checkpoints" / f"ckpt_{pct}.pt"
        ckpt = Checkpoint(self.config.name, pct, step, self.spec, self.config.methods, state, path)
        saved = {f.name: to_json(getattr(ckpt, f.name)) for f in dataclasses.fields(ckpt)}
        torch.save({**saved, "state": {team: dict(s) for team, s in state.items()}}, path)
        return ckpt

    def close(self, status: str, failure: Failure | None = None) -> RunRecord:
        if status not in _CLOSING:
            raise ValueError(f"a run closes as one of {sorted(_CLOSING)}, not {status!r}")
        self._flush()
        self._record = dataclasses.replace(
            self._record, ended=datetime.now(), status=_CLOSING[status], failure=failure
        )
        self._write_record()
        return self._record

    def _flush(self) -> None:
        """Appends the buffered episodes and evaluation points to their JSON Lines logs."""
        for name, items in (("episodes", self._episodes), ("evals", self._evals)):
            with (self.path / f"{name}.jsonl").open("a") as log:
                log.writelines(json.dumps(to_json(item)) + "\n" for item in items)
            items.clear()

    def _write_record(self) -> None:
        """Replaces `run.json` atomically: write a temporary file, then rename it."""
        temporary = self.path / "run.json.tmp"
        temporary.write_text(json.dumps(to_json(self._record), indent=1))
        temporary.replace(self.path / "run.json")


def to_json(value: object) -> object:
    """A contract value as JSON data: dataclasses and mappings as objects, tuples as arrays."""
    if dataclasses.is_dataclass(value) and not isinstance(value, type):
        return {f.name: to_json(getattr(value, f.name)) for f in dataclasses.fields(value)}
    if isinstance(value, Mapping):
        return {str(key): to_json(item) for key, item in value.items()}
    if isinstance(value, (list, tuple)):
        return [to_json(item) for item in value]
    if isinstance(value, Path):
        return str(value)
    if isinstance(value, datetime):
        return value.isoformat()
    return value

TRAINING_SEEDS = 1_000_000  # training episode seeds come from [0, 10**6) (AD-05)


def train_loop(
    world: World, learners: Mapping[str, Learner], config: RunConfig, root: Path
) -> RunRecord:
    """Steps `world` exactly `config.budget` times, writing the run folder under `root`."""
    writer = RunWriter(root, config, world.spec)
    try:
        failure = _train(world, learners, config, writer)
    except KeyboardInterrupt:
        writer.close("incomplete")
        raise
    if failure is not None:
        return writer.close("failed", failure)
    return writer.close("finished")


def _train(
    world: World, learners: Mapping[str, Learner], config: RunConfig, writer: RunWriter
) -> Failure | None:
    """The training steps; the failure if a learner met a non-finite value, else None."""
    # The run seed's first child seeds the learners (train.setup); the next two are ours.
    explore, episode_seeds = (
        np.random.default_rng(child) for child in np.random.SeedSequence(config.seed).spawn(3)[1:]
    )
    judge = copy.deepcopy(world)  # evaluation never touches the training world (AD-05)
    last = _record_marks(0, config.budget, judge, learners, writer)

        try:

                learners[team.name].observe(_transition(team, now, actions, after))
        except NonFiniteError as error:

            after = world.reset(int(episode_seeds.integers(TRAINING_SEEDS)))
        now = after

    return None


def _act(
    spec: WorldSpec, learners: Mapping[str, Learner], obs: Array, rng: np.random.Generator
) -> Array:
    """One action row per agent, each team's rows from its learner."""
    rows: list[Array] = [np.zeros(0)] * len(spec.agents)
    for team in spec.teams:
        team_actions = learners[team.name].act(obs[list(team.agents)], rng)
        for agent, action in zip(team.agents, team_actions, strict=True):
            rows[agent] = action
    return np.stack(rows)


def _transition(team: TeamSpec, before: Step, actions: Array, after: Step) -> Transition:
    """The team's rows of one world step; `active` as it was before the step."""
    rows = list(team.agents)
    return Transition(
        obs=before.obs[rows],
        actions=actions[rows],
        rewards=after.rewards[rows],
        next_obs=after.obs[rows],
        done=after.done,
        truncated=after.truncated,
        active=before.active[rows],
    )


def _record_marks(
    step: int, budget: int, judge: World, learners: Mapping[str, Learner], writer: RunWriter
) -> Checkpoint:
    """Checkpoints due at `step` (every 10%) and evaluations due (every 5%); the last checkpoint
    written, or None."""

            written = writer.checkpoint(pct, step, state)

        m.name: float(np.mean([r.measures[m.name] for r in results])) for m in world.spec.measures
    }
    return EvalPoint(step, scores, measures)
