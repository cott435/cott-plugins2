A report TOML holds a `[players.<name>]` table per player (`runs` or `baseline`, plus `team`
and `vs` for predator-prey), a `[charts]` table (`baselines`, `ladder`, `ablations`,

import dataclasses
import tomllib
from pathlib import Path
from typing import Any, get_args, get_type_hints

from rllab.compare import ClaimSpec
from rllab.lab.types import PlayerTarget, ReportTargets

_TOP_LEVEL = ("players", "charts", "claims")
_CHART_KEYS = ("baselines", "ladder", "ablations", "crossplay")
_DIRECTIONS: tuple[str, ...] = get_args(get_type_hints(ClaimSpec)["direction"])


def load_report_spec(path: Path) -> tuple[list[ClaimSpec], ReportTargets]:
    """Read the claims and the targets; ValueError if a claim names an unlisted player."""
    with path.open("rb") as file:
        raw = tomllib.load(file)
    _check_keys(raw, _TOP_LEVEL, "report")
    players = {name: _player(name, table) for name, table in raw.get("players", {}).items()}
    targets = _targets(players, raw.get("charts", {}))
    claims = [_claim(table, players) for table in raw.get("claims", [])]
    return claims, targets


def _check_keys(table: dict[str, Any], known: tuple[str, ...], where: str) -> None:
    for key in table:
        if key not in known:
            raise ValueError(f"{where}.{key}: unknown key")


def _player(name: str, table: dict[str, Any]) -> PlayerTarget:
    known = tuple(f.name for f in dataclasses.fields(PlayerTarget))
    _check_keys(table, known, f"players.{name}")
    values = dict(table)
    values["runs"] = tuple(Path(run) for run in table.get("runs", ()))
    values["vs"] = tuple(table.get("vs", ()))
    return PlayerTarget(**values)

`load_report_spec` now reads a report TOML and returns the `ClaimSpec` list plus the `ReportTargets`. A claim that names a player not in the file raises `ValueError`. `scripts/check.sh gate` passes, including the 13 new unit tests (`pytest tests/unit/rllab -k report_spec`).

Nothing in the repo defined the report file's layout, so I chose one, and it is set out in the module docstring:
- one `[players.<name>]` table per player, with `runs` or `baseline`, and optionally `team` and `vs` for predator-prey;
- one `[charts]` table with `baselines`, `ladder`, `ablations` and `crossplay`;
- one `[[claims]]` table per claim, with `name`, `a`, `b`, `direction`, and optionally `stretch` and `min_ratio`.

It also raises `ValueError` for an unknown key, a missing claim key or an unknown `direction`. A chart naming an unlisted player fails through the frozen `ReportTargets` check.

Run and chart paths are kept exactly as written, not resolved against the TOML's folder. That matches CLI use from the project root (`reports/smoke.toml` pointing at `runs/...`). If later tasks expect paths relative to the TOML file, this needs changing.

The tests cover reading the claims and targets, matching the `lab.ReportTargets` contract sample (`m1_snake.json`), files with no claims or charts, and each error path.
