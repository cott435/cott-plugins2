# Frontend Design (eval stub)

This is a placeholder for Anthropic's `frontend-design` skill during a planning-docs eval. The full guidance is not loaded here.

When planning documents need UI work, reference this skill by name (`frontend-design`) at the point where the interface is built, and write down what it will be given:

- who uses the interface and for what, in plain words
- the views and what each one shows
- the data each view gets from the backend, by contract
- the aesthetic direction and any fixed constraints (framework, local-only)

Do not design or write any UI during planning.
