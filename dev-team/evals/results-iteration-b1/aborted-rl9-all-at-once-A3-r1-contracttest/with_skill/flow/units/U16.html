116	### AD-05: Seeds from SeedSequence, disjoint held-out ranges, one process per run
117	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** system
118	- **Context:** WORLD-01, WORLD-02, TRAIN-02 and REPLAY-02 need exact repeats; TRAIN-04 and EVAL-03 need seeds never used in training; TRAIN-05 and QR-02 need runs in parallel, one per core.
119	- **Decision:** A run seed spawns the learner's, exploration and episode-seed generators through `np.random.SeedSequence`. An episode seed spawns the world's and the policies' generators inside `core.play_episode`. Training draws episode seeds from [0, 10⁶); evaluation seeds are the fixed `core.EVAL_SEEDS` and `core.FINAL_SEEDS` ranges (see Data). `train.run_batch` runs each config in its own `spawn` process with `torch.set_num_threads(1)` and `torch.use_deterministic_algorithms(True)`.
120	- **Alternatives:** Global `np.random.seed`/`torch.manual_seed`: order-dependent, breaks once evaluation interleaves with training. Threads: the GIL serialises the Python world loop.
121	- **Consequences:** Identical runs are promised on the same machine only (TRAIN-02). In-training evaluation never touches the training generators, so turning evaluation off for a test leaves training identical.

123	### AD-06: Run folders of JSON, JSON Lines and torch checkpoints
124	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** system
125	- **Context:** LOG-01 and LOG-02 need a record and per-episode logs. LOG-06 needs them readable while the run writes, at most one evaluation point behind. 126	- **Decision:** One folder per run (see Data). Logs are append-only JSON Lines, flushed at every evaluation point; `run.json` is rewritten atomically (write, then rename) on each status change. 127	- **Alternatives:** Parquet: fast to read but not appendable while a run is live. SQLite: one file for everything, but concurrent writers from parallel runs need care and the files are no longer readable by eye.
128	- **Consequences:** Charts and evaluation read whole JSONL files; at ~10⁴ episodes per run that is instant. A crashed process leaves `run.json` at `running`; `runlog` reports any `running` run with no live process as incomplete.

131	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** system
132	- **Context:** REPLAY-01–REPLAY-08 need any checkpoint or baseline from any seed, step back, 4 speeds, side by side, a sight overlay and video export. QR-04 needs ≥ 30 steps/s; QR-06 needs it offline. Worlds are deterministic (AD-05), so nothing needs recording during training.

139	- **Context:** CHECK-02 needs an established implementation of the same kind of method (DQN, PPO; AD-03) trained on the same world, budget and seeds; CHECK-01 forbids it inside training runs. Worlds speak `core.World`, not Gymnasium (AD-04).

It trains SB3 `DQN` or `PPO` for 5 seeds and evaluates on `core.FINAL_SEEDS` through `core.play_episode`. 144	### AD-09: Every batch first runs the method's check world
145	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** system
146	- **Context:** TRAIN-06 needs every learning method to learn a hand-derived best behaviour before it is used in a world. Bugs in RL are silent (brief), and methods change while a world is built.
147	- **Decision:** `train.run_check` trains each team method in a config on its check world: for DQN a 6-state corridor with two exits, left of state 0 (reward 0.8) and right of state 5 (reward 1.0), γ = 0.9, so the best action is left in states 0–1 and right in 2–5 and a learner biased to one action can't pass; for PPO a 1-D point that is rewarded for reaching a target, where the best push is the sign of the offset. 148	- **Alternatives:** A recorded pass per method version: saves seconds but goes stale silently when code changes. A test only: passes in CI but not for the settings actually used.
149	- **Consequences:** Each batch spends under a minute on the check. A check-world settings override exists because a world's tuned settings (e.g. buffer size) may be too large for a 6-state world.

152	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** system
153	- **Context:** Pipeline design gave every workflow one entry function calling named steps (PL-01–PL-12). Entries import their steps' owners, so where an entry lives sets an import direction. 154	- **Decision:** `train` hosts the PL-01–PL-03 entries (`run_check`, `run_train`, `run_batch`) and exports them as its contract. Every other entry lives in `cli/pipelines/`. 156	- **Consequences:** The contract carries the train entries, the config loader and every step function a `cli` entry calls. `cli` has no step tests; its intent tests drive `main` with arguments.

def check_plan(configs: Sequence[RunConfig]) -> dict[str, MethodConfig]:
    """Each distinct team method, keyed by method name, with `check_settings` applied."""
    plan: dict[str, MethodConfig] = {}
    for config in configs:
        for team in config.methods.values():
            if team.method not in plan:
                overrides = config.check_settings.get(team.method, {})
                plan[team.method] = replace(team, settings={**team.settings, **overrides})
    return plan


def train_checks(plan: Mapping[str, MethodConfig], seed: int) -> dict[str, Learner]:
    """A learner per method, trained on its check world for the fixed check budget."""
    return {name: _train_check(config, seed) for name, config in plan.items()}


def score_checks(
    learners: Mapping[str, Learner], plan: Mapping[str, MethodConfig]
) -> list[CheckResult]:
    """Per method, the share of check-world states where `policy().act` is the best action."""
    return [_score_check(learners[name], config) for name, config in plan.items()]


def require_pass(results: Sequence[CheckResult]) -> list[CheckResult]:
    """`results` unchanged if all passed; `CheckFailedError` on the first failure."""
    failed = next((result for result in results if not result.passed), None)
    if failed is not None:
        raise CheckFailedError(failed)
    return list(results)


def _check_world(config: MethodConfig) -> CheckWorld:
    """The method's check world; `worlds.make` serves a `CheckWorld` for these names."""
    return cast("CheckWorld", make(CHECK_WORLDS[config.method]))


def _train_check(config: MethodConfig, seed: int) -> Learner:
    """Step the method's learner on its check world for `CHECK_BUDGET` world steps."""
    world = _check_world(config)
    team = world.spec.teams[0]
    rows = list(team.agents)
    learner_seq, explore_seq, episode_seq = np.random.SeedSequence(seed).spawn(3)
    learner = make_learner(config, world.spec, team.name, np.random.default_rng(learner_seq))
    explore, episodes = np.random.default_rng(explore_seq), np.random.default_rng(episode_seq)
    step = world.reset(int(episodes.integers(EPISODE_SEED_LIMIT)))
    for _ in range(CHECK_BUDGET):
        actions = learner.act(step.obs[rows], explore)
        after = world.step(actions)
        learner.observe(
            Transition(
                obs=step.obs[rows],
                actions=actions,
                rewards=after.rewards[rows],
                next_obs=after.obs[rows],
                done=after.done,
                truncated=after.truncated,
                active=step.active[rows],
            )
        )
        ended = after.done or after.truncated
        step = world.reset(int(episodes.integers(EPISODE_SEED_LIMIT))) if ended else after
    return learner


def _score_check(learner: Learner, config: MethodConfig) -> CheckResult:
    """Agreement of the frozen policy with the check world's hand-derived best actions."""
    world = _check_world(config)
    states, best = world.states(), world.best_actions()
    chosen = learner.policy().act(states, np.random.default_rng(0))
    margin = BOX_MARGIN if isinstance(world.spec.action, Box) else 0.0
    n = len(states)
    gap = np.abs(np.reshape(chosen, (n, -1)).astype(np.float64) - np.reshape(best, (n, -1)))
    agreement = float(np.mean(np.all(gap <= margin, axis=1)))
    return CheckResult(
        method=config.method,
        world=world.spec.world,
        agreement=agreement,
        passed=agreement >= PASS_AT,
    )

class FixedPolicy:
    def __init__(self, actions: np.ndarray) -> None:
        self.actions = actions
        self.seen: list[np.ndarray] = []

    def act(self, obs: np.ndarray, rng: np.random.Generator) -> np.ndarray:
        self.seen.append(obs)
        return self.actions


class FixedLearner:
    """A learner whose frozen policy always answers `actions`; only `policy()` is used."""

    def __init__(self, actions: np.ndarray) -> None:
        self._policy = FixedPolicy(actions)

    def act(self, obs: np.ndarray, rng: np.random.Generator) -> np.ndarray:
        raise AssertionError("scoring must use the frozen policy")

    def observe(self, t: object) -> None:
        raise AssertionError("scoring must not train")

    def policy(self) -> FixedPolicy:
        return self._policy

    def state_dict(self) -> dict[str, object]:
        return {}
