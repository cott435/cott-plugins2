81	**Status:** Accepted · **Date:** 2026-10-17 · **Scope:** `runs`
82	- **Context:** RUN-01 needs a run fully described by its settings. RUN-02 needs settings, seed, curve, checkpoint and games saved. RUN-05 needs reloading. The interrupted-run edge case needs partial records kept.
83	- **Decision:** Settings are read from TOML into a frozen `core.RunSettings`. 176	### core.Env: type
177	```python
178	class Env(Protocol):
179	    teams: Mapping[str, TeamSpec]
180	    board: Literal["grid", "tank"]
181	    def reset(self, seed: int) -> tuple[dict[str, np.ndarray], dict[str, float]]: ...
182	    def step(self, actions: Mapping[str, np.ndarray]) -> StepResult: ...
183	    def frame(self) -> np.ndarray: ...
184	```
185	- **Invariants:** teams, each batch-first (AD-09, AD-13): observations map each team name to float32 `(n_agents, *obs_shape)` from its `TeamSpec`, and `actions` maps each team to `(n_agents,)` int64 when discrete or `(n_agents, dim)` float32 when continuous. Single-team environments have one team, `"agents"` (`core.SOLO`). Entries for agents already done are ignored. `info` always holds `steps`, `score:<team>` for each team, and `score` for the first team. `frame()` is an int8 grid of cell codes (0 empty, 1 head, 2 body, 3 food or goal) when `board == "grid"`, and a `(K, 4)` float32 array of circles `(x, y, radius, kind)` when `board == "tank"`, with kinds 0 ball, 1 fish, 2 caught fish, 3 predator, 4 prey, 5 caught prey, 6 pellet (AD-12).
