featureAGENTValue-learning agentadded
stagesS1
stage_viaStage line

servesG1, G2
requirementAGENT-01The agent estimates, for each observation, a value for every allowed move.added
criteria
  • Given an observation of 11 facts, when the agent is asked, then it returns 3 values, one per move.
requirementAGENT-02During training the agent takes a random move with a probability that starts at 1.0 and decays to 0.01 over the first half of the training games, and otherwise takes its best-valued move.added
criteria
  • Given training game 0, when the agent picks moves, then every move is random; given a game in the second half, then about 1% of moves are random.
requirementAGENT-03During evaluation the agent always takes its best-valued move.added
criteria
  • Given an evaluation game, when the agent picks a move, then it is the move with the highest value, and the same observation always gives the same move.
requirementAGENT-04The agent remembers its most recent 100,000 steps and learns from random batches of them.added
criteria
  • Given more than 100,000 steps taken, when the agent learns, then its batches come only from the latest 100,000 steps, drawn at random.
requirementAGENT-05The agent's learning targets are the step's reward plus the discounted best value of the next observation (discount 0.9), taken from a frozen copy of its value estimate that is refreshed every 1,000 steps; a game-ending step's target is its reward alone.added
criteria
  • Given a non-final step with reward 0, when its target is built, then it equals 0.9 × the frozen copy's best value for the next observation.
  • Given a game-ending step with reward −10, when its target is built, then it is −10.
  • Given 1,000 learning steps since the last refresh, when the next one happens, then the frozen copy is replaced by the current estimate.
requirementAGENT-06A trained agent can be saved and loaded back, and the loaded agent picks the same moves.added
criteria
  • Given a saved agent, when it is loaded and plays an evaluation game with seed 11, then it makes exactly the same moves as before saving.

requirementSNAKE-01The game is played on a 20 × 20 grid with a snake that starts 3 cells long in the middle, heading right.added
criteria
  • Given a new game, when it starts, then the snake occupies 3 adjacent cells in the middle of the grid, heading right, and exactly one food is on a cell the snake does not occupy.
requirementSNAKE-02Each step the agent chooses one of 3 moves relative to the snake's heading: straight, turn left or turn right.added
criteria
  • Given the snake heading up, when the agent picks "turn left", then the head moves one cell left and the heading becomes left.
  • Given any heading, when any of the 3 moves is picked, then the snake never reverses into its own neck.
requirementSNAKE-03Moving the head onto the food grows the snake by 1 cell, adds 1 to the score and places new food on a random empty cell.added
criteria
  • Given food directly ahead, when the agent moves straight, then the snake is 1 cell longer, the score rises by 1 and a new food appears on a cell the snake does not occupy.
requirementSNAKE-04Moving the head into a wall or into the snake's own body ends the game.added
criteria
  • Given the head next to the right wall heading right, when the agent moves straight, then the game ends with its current score.
  • Given the head beside its own body, when the agent turns into it, then the game ends.
requirementSNAKE-05A game also ends when the snake goes 100 × its length steps without eating.added
criteria
  • Given a snake of length 5 that has not eaten for 500 steps, when it takes another step without eating, then the game ends with its current score.
requirementSNAKE-06The agent observes exactly 11 yes/no facts each step: danger straight ahead, danger to the left, danger to the right (danger = wall or body in the adjacent cell); heading up, down, left, right; food is up, down, left, right of the head.added
criteria
  • Given the head heading right with the wall in the next cell and food above-left, when the agent observes, then "danger straight", "heading right", "food up" and "food left" are yes and the other 7 facts are no.
requirementSNAKE-07Rewards are +10 for eating food, −10 for the game ending by collision or step limit, and 0 for every other step.added
criteria
  • Given a step that eats food, when the reward is reported, then it is +10; given a step that ends the game, then it is −10; given any other step, then it is 0.
requirementSNAKE-08A game started with the same seed and played with the same moves unfolds identically, including every food position.added
criteria
  • Given seed 7 and a fixed list of moves, when the game is played twice, then every frame, reward and the final score are identical.
